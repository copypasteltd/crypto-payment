## 2. 当前文件链事实矩阵

| 证据 | 当前实现 | 当前含义 | 当前缺口 |
|---|---|---|---|
| `GET /files/download` | 直接流式读取宿主机文件 | 当前仅支持本地文件直下 | 无短时授权 |
| `getRunFileDownloadUrl()` + `createRunDownloadTicket()` | 票据化下载 URL | Dashboard 已通过 SDK 收口下载能力 | URL 升级可统一在 SDK 收敛 |
| `getRunFileDownloadUrl()` + `createRunDownloadTicket()` | 票据化下载 URL | Mobile 已通过 SDK 收口下载能力 | 小程序/H5 只保留终端下载动作差异 |
| `readRunFile()` | 文本预览上限 256 KB | 仅文本预览已有基础 | 图片/PDF/Office 无正式 preview |
| 附件链文档 | 已设计 `upload_ticket/input_material/message_attachment` | 上传模型已定义方向 | 代码未实现 |

## 3. 上传会话执行矩阵

| 步骤 | 执行方 | 正式输入 | 正式动作 | 输出 |
|---|---|---|---|---|
| 1 | 前端 | `filename/mime/size/material_kind/logical_path` | 请求创建上传会话 | `upload_session` |
| 2 | API | 当前用户 + run/workspace 权限 | 校验类型、大小、路径与 quota | `upload_ticket` |
| 3 | 前端 | `upload_ticket` + 文件内容 | 直传对象存储或 multipart | 已上传 blob |
| 4 | API | `upload_session_id/checksum/storage_key` | 完成确认并写 `run_file/input_material` | 文件元数据对象 |
| 5 | Worker / run | 新文件索引事件 | 将输入映射到 `inputs/` 或直接以对象引用消费 | runtime 可见材料 |

## 4. `upload_ticket` 字段执行矩阵

| 字段 | 当前建议 | 作用 |
|---|---|---|
| `upload_session_id` | `fus_*` | 上传会话主键 |
| `upload_mode` | `presigned-put / multipart / gateway-proxy` | 客户端上传方式 |
| `method` | `PUT/POST` | 上传方法 |
| `url` | string | 上传地址 |
| `headers` | object | 必填签名头 |
| `part_size_bytes` | number | multipart 分片大小 |
| `expires_at` | datetime | 会话过期时间 |
| `storage_key` | string | 预分配对象 key |

## 5. 完成上传确认执行矩阵

| 步骤 | API 当前需要做的事 | 正式落点 |
|---|---|---|
| 校验会话状态 | `issued/uploading` 才允许完成 | `file_upload_session.status` |
| 校验对象存在 | HEAD 对象存储，核对大小与 checksum | `file_blob` |
| 写文件元数据 | 生成 `run_file` | DB |
| 追加附件绑定 | 如来自消息附件，则写 `message_attachment_binding` | DB |
| 广播文件变更 | 推送 `file.changed` 或 `files.synced` | 实时链 |
| 写审计日志 | 记录上传人、run、workspace、来源 | `file_access_log` / audit |

## 6. 下载授权执行矩阵

| 步骤 | 执行方 | 正式动作 | 输出 |
|---|---|---|---|
| 1 | 前端 | 请求下载 grant | `download_grant_request` |
| 2 | API | 校验用户、工作区、run、文件、来源类型 | 是否允许下载 |
| 3 | API | 生成 `file_download_grant` | grant 记录 |
| 4 | API | 返回 `signed-url / gateway-stream / miniapp-proxy` | `download_payload` |
| 5 | 前端 | 按终端类型下载 | 浏览器或小程序下载结果 |
| 6 | API | 消费/撤销 grant 并记日志 | 访问审计 |

## 7. 预览变体执行矩阵

| 文件类型 | 正式预览策略 | 生成方式 | 前端消费 |
|---|---|---|---|
| 文本/JSON/Markdown/CSV | 范围读取或全文拉取 | 直接从对象读取 | 文本预览页 |
| 图片 | 原图 + 缩略图 | 上传后异步生成缩略图 | 图片查看器 |
| PDF | 封面图 + 页图 + 原文件 | 异步渲染 preview variant | 内嵌 PDF 页预览 |
| Office | 转 PDF 或 HTML 预览 | 异步转换任务 | 预览页或下载页 |
| zip / binary | 不做内容预览 | 仅元数据 | 仅下载 |
| 日志 | 尾部读取 + 分页 | 范围读取 | 日志页 |

## 10. 双端下载消费执行矩阵

| 终端 | 当前行为 | 正式行为 |
|---|---|---|
| Dashboard Web | `window.open(url)` | SDK 先请求 grant，再决定 open/blob/save |
| Mobile H5 | `window.open(url)` | SDK 先请求 grant，再按浏览器能力选择 |
| WeChat/Alipay 小程序 | `downloadFile(url)` | SDK 返回 `miniapp-proxy` 或短时 URL，统一错误处理 |

## 14. 当前阻塞项总表

| 阻塞项 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无上传会话接口 | 补材料无法正式化 | 文件输入链断裂 | P0 |
| 无下载授权对象 | 下载全靠本地路径直出 | 安全与审计不足 | P0 |
| 无预览变体体系 | 图片/PDF/Office 体验不完整 | 双端体验不足 | P1 |
| SDK 无上传/下载统一门面 | 双端各自实现 | 行为不一致 | P1 |
