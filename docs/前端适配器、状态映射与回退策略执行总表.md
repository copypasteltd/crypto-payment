## 4. Mobile 状态映射矩阵

| `RunStatus` | `status` | `statusLabel` | `statusClass` | `stage` |

## 5. 双端状态差异矩阵

| 场景 | Dashboard 当前行为 | Mobile 当前行为 | 风险 |
|---|---|---|---|
| `FAILED` | `danger` + 失败 | `approval/warn` + 失败 | 语义不一致 |
| `CANCELLED` | 独立取消状态 | 仍归入 `running` 组 | 统计口径不一致 |
| `SUCCEEDED` | 直接建议查看结果文件 | 归入完成态并继续支持派生对话 | 行为差异可接受，需文档化 |
| `CREATED` | 待补充 | 运行中 | 首轮信息收集阶段认知不一致 |

## 14. 适配层风险矩阵

| 风险 | 当前表现 | 影响 |
|---|---|---|
| 状态语义不统一 | Dashboard 与 Mobile 对 `FAILED/CANCELLED/CREATED` 映射不同 | 数据看板与用户认知不一致 |
| 工坊名靠字符串推断 | `taskVersionId` 命名变化会导致展示漂移 | 展示不稳定 |
| 文件辅助文案硬编码 | 缺 MIME/权限粒度 | 预览体验受限 |
| Mobile 默认工作区回退固定 | 未识别值会落到 `harbor-finance` | 可能误导用户 |

## 15. 当前阻塞项总表

| 阻塞项 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无统一 ViewModel 层 | 双端适配逻辑分叉 | 维护成本高 | P0 |
| 状态映射不一致 | 失败/取消/待补充语义不同 | 统计和交互不稳定 | P0 |
| 工坊/空间元数据仍靠推导 | 缺正式后端字段 | 展示漂移风险高 | P1 |
| 静态原型数据仍参与页面主流程 | 联调时易混淆真实链路 | 接口接入风险高 | P1 |
