# 灵办词元 Mobile 任务工作区边界收口（2026-07-09）

## 1. 本轮目标

补齐移动端任务详情页与文件页的工作区边界反馈，解决两类问题：

| 问题 | 风险 |
|---|---|
| 越界任务链接只表现为普通空状态 | 用户无法判断是没有任务还是进入了错误工作区 |
| 越界文件页缺少明确反馈 | 用户会误以为文件链路异常或数据丢失 |

## 2. 已落地变更

| 项目 | 结果 |
|---|---|
| 任务跨工作区识别 | 已落地 |
| 文件页跨工作区识别 | 已落地 |
| 静态任务跨工作区识别 | 已落地 |
| 越界状态反馈 | 显式提示“当前任务/文件不属于这个工作区” |
| 用户动作出口 | 提供“返回任务列表 / 切换工作区”入口 |

| `app/mobile/src/pages/tasks/files.tsx` | 文件页越界识别与显式提示 |

## 5. 当前影响

| 维度 | 影响 |
|---|---|
| 可用性 | H5 任务链路对工作区边界的反馈更清晰 |
| 误操作风险 | 降低用户在错误空间里继续判断任务状态的概率 |
| 数据链可信度 | 区分“空状态”和“越界状态”，前端语义更接近真实后端边界 |
