## 2. 打分规则表

| 分值 | 含义 |
|---|---|
| 0 | 完全缺失，无代码或无证据 |
| 1 | 有设计或骨架，不能联调 |
| 2 | 有局部实现，缺乏主链证据 |
| 3 | 主链可运行，但缺少稳定性或治理证据 |
| 4 | 主链与主要治理项都成立，仍有次级缺口 |
| 5 | 里程碑目标完整达成，证据充分 |

## 3. Gate 决策规则表

| 结论 | 条件 |
|---|---|
| `Go` | 总分达到阈值，且无硬阻塞项 |
| `Conditional Go` | 总分接近阈值，但需带整改项进入下阶段 |
| `No-Go` | 总分低于阈值，或存在任一硬阻塞项 |

| 条件 | 说明 |

| 总分距离阈值不超过 10 分 | 说明主体基本可用 |
