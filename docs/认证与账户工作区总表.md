## 10. 建议角色矩阵表

| 角色 | 作用域 | 核心权限 |
|---|---|---|
| Workspace Owner | 工作区级 | 管理成员、凭证、MCP、配额、所有 run |
| Workspace Admin | 工作区级 | 管理服务启停、审计查看、部分治理 |
| Operator | 工作区级 | 创建 run、发送消息、查看结果 |
| Approver | 工作区级 | 执行高风险审批 |
| Creator Maintainer | Creator 空间级 | 管理 package、版本、发布 |
| Auditor | 平台或工作区级 | 查看审计、成本、策略命中 |
| Personal User | 个人空间级 | 管理自己的运行与文件 |

## 11. 建议认证接口总表

| 接口 | 作用 |
|---|---|
| `POST /auth/login` | 用户登录 |
| `POST /auth/refresh` | 刷新访问令牌 |
| `POST /auth/logout` | 注销当前会话 |
| `GET /auth/me` | 获取当前用户 |
| `GET /workspaces` | 获取当前用户可访问工作区列表 |
| `GET /workspaces/:workspaceId` | 获取工作区详情 |
| `GET /workspaces/:workspaceId/members` | 获取成员列表 |
| `POST /workspaces/:workspaceId/switch` | 记录默认工作区切换 |
| `POST /workspaces/:workspaceId/invitations` | 发起邀请 |

## 14. 运行授权判定链路总表

| 阶段 | 判定内容 |
|---|---|
| 前端选工作区 | 当前用户是否可见该工作区 |
| 前端创建 run | 当前用户是否有该服务执行权 |
| API 接收 `createRun` | 校验用户、工作区、taskVersion、sessionVersion、凭证绑定权限 |
| Worker 物化 runtime | 只物化当前 run 允许的最小凭证与 MCP |
| Bridge 回调事件 | 仅允许回写当前 run |
| 文件下载 | 当前用户是否有该 run 文件读取权限 |

## 17. 当前阻塞项总表

| 阻塞项 | 当前原因 | 优先级 |
|---|---|---|
| 细粒度 RBAC 缺失 | 当前仍以基础工作区角色判定为主 | P0 |
| 用户/工作区表正式迁移不足 | PostgreSQL 已具基础 repository，但正式迁移与运营数据域仍未完整 | P0 |
| 前端资源守卫不完整 | 前端仍有原型态开放区块与静态目录数据 | P0 |
| 工作区权限策略细化不足 | run 创建与文件访问已绑定 actor，但 service/credential/MCP 粒度仍不足 | P0 |
| 内部回调强鉴权不足 | 已有 internal token，仍缺轮换、trace 和更强身份机制 | P1 |
