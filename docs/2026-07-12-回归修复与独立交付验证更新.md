## 3. 本轮修复项

### 3.1 Session-pack 治理修复

| 文件 | 修复内容 | 作用 |
|---|---|---|
| `app/api/src/modules/sessions/service.ts` | 在 `buildSessionPackGovernancePolicySummary(...)` 中增加 `signatureGovernanceApplies` 判定 | 将验签治理限定到真实归档态 session-pack，避免纯 catalog 生成态 descriptor 被错误阻断 |
| `app/api/src/modules/sessions/service.ts` | 对 `inherit / publish / rollback` 的验签、key acceptance、key distribution、active signing drift 等检查统一加门控 | 保留 imported / runtime-derived 归档的严格治理，恢复 creator/workshop 生成态运行链路 |

### 3.2 Standalone 导出增强

| 文件 | 修复内容 | 作用 |
|---|---|---|
| `infra/scripts/export-standalone-workspace.mjs` | 根脚本包装中增加内部 workspace 依赖预构建 | 解决独立 workspace 中应用 build/typecheck 时内部包尚未构建的问题 |
| `infra/scripts/export-standalone-workspace.mjs` | 生成根 `package.json` 时补齐根级 `devDependencies` | 解决 `tsc` 等根工具链二进制在独立 workspace 中不可见的问题 |
| `package.json` | 新增 `standalone:export` / `standalone:export:all` | 提供标准化独立交付导出入口 |
| `.gitignore` | 增加 `standalone/` | 避免导出产物污染源码工作区 |

## 5. 本轮关闭的问题单

| 问题 | 原因 | 当前状态 |
|---|---|---|
| `SESSION_PACK_GOVERNANCE_POLICY_BLOCKED` 阻断 creator/workshop 运行 | 生成态 session-pack 被错误按“未验签归档”处理 | 已关闭 |
| `batch-runs.smoke` 中 batch item 无 `runId` | 上游 run 创建被 session-pack 治理阻断 | 已关闭 |
| `standalone` workspace 中 `tsc not recognized` | 根工具链未被带入导出包 | 已关闭 |
| `standalone dashboard/backend` 无法独立 `validate` | 内部 workspace 依赖未预构建，根工具链缺失 | 已关闭 |
| `run-worker` 独立包无法解析 `session-pack` | 代码使用相对路径直连 `packages/session-pack/dist`，且包依赖缺失 | 已关闭 |
| `dashboard` 主入口 chunk 超过 warning 阈值 | vendor 与状态类依赖未拆包 | 已关闭 |
