## 8. 审计导出任务状态机表

| 状态 | 含义 | 进入条件 | 可流转 |
|---|---|---|---|
| `queued` | 已建任务，等待执行 | 用户提交导出请求 | `collecting`、`failed` |
| `collecting` | 拉取审计数据、消息、审批、文件索引 | worker 开始处理 | `masking`、`failed` |
| `masking` | 按导出 profile 做脱敏 | 数据收集完成 | `packaging`、`failed` |
| `packaging` | 生成清单、压缩包、摘要 | 脱敏完成 | `ready`、`failed` |
| `ready` | 导出包可下载 | 包上传成功 | `expired` |
| `failed` | 导出失败 | 任一阶段异常 | 无 |
| `expired` | 下载链接过期 | 到达 `expires_at` | 无 |
