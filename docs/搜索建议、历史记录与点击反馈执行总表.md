## 4. 当前交互执行表

| 场景 | 当前行为 | 当前结果 | 当前问题 |
|---|---|---|---|
| Dashboard 输入框 focus | `setSearchPanelOpen(true)` | 打开浮层 | 无最近历史/建议内容 |
| Dashboard 空查询 | 渲染三条静态 searchable surfaces 文案 | 用户只看到说明文本 | 不具备可点击建议 |
| Dashboard 输入关键词 | 每次字符变化立刻本地 `useMemo` 过滤 | 最多展示 8 条结果 | 无防抖、无排序反馈 |
| Dashboard 点击结果 | `navigate(item.route)` 并关闭浮层 | 完成跳转 | 无 click 记录、无 rank feedback |
| Mobile 页面内搜索 | 本地过滤当前数组 | 列表即时变化 | 无跨页统一搜索闭环 |

## 5. 当前建议缺口矩阵表

| 缺口 | 当前表现 | 直接影响 | 优先级 |
|---|---|---|---|
| 无建议对象 | 只有结果，没有建议 | 无法承载 prefix hit、历史推荐、热门推荐 | P0 |
| 无历史对象 | 用户重复搜索无复用 | 搜索体验割裂 | P1 |
| 无点击反馈 | 排序永远是静态顺序 | 无法形成行为优化 | P1 |
| 无拼音/别名支持 | 中文长名称只能全文包含 | 搜索召回不足 | P1 |
| 无隐私分级 | 搜索内容若落历史，缺审计与脱敏规则 | 合规风险 | P1 |

## 7. 正式对象表

### 7.1 行为对象表

| 对象 | 主键 | 核心字段 | 说明 |
|---|---|---|---|
| `search_history_entry` | `history_id` | `user_id`、`workspace_id`、`query`、`query_terms[]`、`last_used_at`、`use_count` | 用户搜索历史 |
| `search_click_event` | `event_id` | `user_id`、`workspace_id`、`query`、`document_id`、`rank`、`clicked_at`、`surface` | 搜索点击反馈 |
| `search_query_session` | `session_id` | `user_id`、`workspace_id`、`started_at`、`last_query`、`surface` | 一次搜索会话 |

### 7.2 建议对象表

| 对象 | 主键 | 核心字段 | 说明 |
|---|---|---|---|
| `search_suggestion` | `suggestion_id` | `workspace_id`、`suggestion_type`、`label`、`keywords[]`、`source_ref`、`score` | 单条搜索建议 |
| `search_suggestion_set` | `set_id` | `query_prefix`、`workspace_id`、`items[]`、`generated_at` | 某前缀对应的建议集合 |
| `search_alias_entry` | `alias_id` | `resource_type`、`resource_id`、`alias`、`alias_type` | 拼音、简称、别名、行业关键词 |

## 9. 排序与合流执行表

| 阶段 | 输入 | 动作 | 输出 |
|---|---|---|---|
| 1 | 当前 query prefix | 命中 prefix / alias / keyword | 候选 suggestions |
| 2 | 候选 suggestions + recent history | 按 `score_boost + recent_use + click_rate` 排序 | 建议列表 |
| 3 | 用户点击 suggestion | 写 `search_click_event` | 点击反馈 |
| 4 | 搜索结束 | 更新 `search_history_entry.use_count/last_used_at` | 历史记录 |
| 5 | 夜间/准实时作业 | 根据 click / conversion 重算 score | 新的 suggestion 排序权重 |

## 10. 查询前端执行矩阵表

| 终端 | 输入时机 | 建议触发 | 点击后动作 | 当前建议 |
|---|---|---|---|---|
| Dashboard 顶栏 | `onChange` | `300ms` 防抖后拉 `/v1/search/suggestions` | 记 click -> navigate -> 关闭浮层 | 最先落地 |
| Dashboard 页面内搜索 | `onChange` | 仍可保留本地过滤 | 可选写页面内 click event | 第二阶段补齐 |
| Mobile 全局搜索入口 | 新增统一搜索页或顶部搜索层 | `300ms` 防抖后拉 suggestions | 记 click -> 深链 | 后续补齐 |
| Mobile 页面内搜索 | 当前保留本地过滤 | 可选下沉为统一搜索组件 | 点击结果记 feedback | 后续收敛 |

## 11. 接口执行表

| 方法 | 路径 | 主要参数 | 返回 | 作用 |
|---|---|---|---|---|
| `GET` | `/v1/search/suggestions` | `workspaceId`、`q`、`types[]`、`limit` | `search_suggestion[]` | 拉取建议 |
| `GET` | `/v1/search/history` | `workspaceId`、`limit` | `search_history_entry[]` | 拉取历史 |
| `POST` | `/v1/search/history` | `query`、`workspaceId`、`surface` | `search_history_entry` | 写历史 |
| `POST` | `/v1/search/clicks` | `query`、`documentId`、`rank`、`surface` | `204` | 写点击反馈 |
| `DELETE` | `/v1/search/history/:historyId` | 无 | `204` | 删除单条历史 |
| `DELETE` | `/v1/search/history` | `workspaceId` | `204` | 清空历史 |

## 12. Query Key 与缓存表

| 资源 | Query Key 建议 | 缓存策略 | 失效条件 |
|---|---|---|---|

| hot resources | `["search","hot",workspaceId,types]` | 中缓存 | 读模型刷新、工作区切换 |

## 13. 点击反馈与排序回写表

| 行为 | 当前状态 | 正式动作 |
|---|---|---|
| 点击 suggestion | 无记录 | 写 `search_click_event` |
| 结果跳转成功 | 无记录 | 记录 `resolved_route` |

## 14. 隐私与治理表

| 场景 | 风险 | 正式要求 |
|---|---|---|
| 搜索 query 包含敏感实体名 | 历史记录敏感化 | 支持 workspace policy 控制是否记录全文 |
| 高敏搜索词 | 合规风险 | 支持脱敏存储或完全不入历史 |
| 管理员导出搜索行为 | 过度暴露个人意图 | 默认仅聚合统计，不导出原 query |
| 多工作区搜索 | 串空间风险 | history / click 全部强绑定 `workspace_id` |

## 16. 验收判定表

| 验收项 | 判定标准 |
|---|---|
| 建议可用 | 输入 query 后出现可点击 suggestions，不再只显示静态说明 |
| 历史可回放 | 同一用户可看到并复用自己的最近搜索 |
| 点击可回写 | 点击 suggestion 后会记录 click event 并用于后续排序 |
| 工作区隔离 | A 工作区的历史与建议不会出现在 B 工作区 |
| 隐私可控 | 高敏搜索词可按策略不入历史或脱敏 |

## 17. 当前阻塞表

| 阻塞项 | 影响 | 优先级 |
|---|---|---|
| 当前搜索仍主要基于静态数据 | suggestion 质量与正式资源不一致 | P0 |
| 无用户会话正式域 | history/click 无法精确归属到用户 | P0 |
| Mobile 无统一全局搜索入口 | 双端建议链无法统一 | P1 |
