## 11. 移动端任务链路矩阵表

| 流程阶段 | 页面 | 当前动作 | 当前后端依赖 |
|---|---|---|---|
| 发现服务 | `workshops/index` / `workshops/detail` | 浏览工坊与服务 | 当前以后端无关 |
| 启动实例 | `services/detail` | 调用 `createRun` | 依赖 `POST /v1/runs` |
| 查看任务列表 | `tasks/index` | 获取当前空间 run 列表并映射 | 依赖 `GET /v1/runs` |
| 对话执行 | `tasks/detail` | 读取快照、订阅实时、发消息 | 依赖 `GET /v1/runs/:id`、WS/SSE、`POST /messages` |
| 查看文件 | `tasks/files` | 列树、读文件、下载文件 | 依赖 `GET /files/tree`、`GET /files/read`、下载 URL |

## 12. 页面与接口契约对应表

| 前端能力 | 当前调用接口 | 当前契约对象 | 备注 |
|---|---|---|---|
| 创建 run | `POST /v1/runs` | `CreateRunInput`、`CreateRunResponse` | Dashboard / Mobile 共用 |
| 读取 run 快照 | `GET /v1/runs/:runId` | `RunSnapshot` | 对话页和文件页共用 |
| 列出 runs | `GET /v1/runs` | `RunSnapshot[]` | 列表页和摘要页共用 |
| 查询收藏工坊 | `GET /v1/me/favorites/workshops` | `MeFavoriteWorkshopListResponse` | Mobile 工坊页与我的页共用 |
| 收藏切换 | `PUT /v1/me/favorites/workshops/:workshopId` | `SetMeFavoriteWorkshopInput`、`SetMeFavoriteWorkshopResult` | Mobile 工坊页收藏按钮 |
| 发送消息 | `POST /v1/runs/:runId/messages` | `SendRunMessageInput`、`RunSnapshot` | 对话页主动作 |
| 读取文件树 | `GET /v1/runs/:runId/files/tree` | `RunFileEntry[]` | 文件页核心入口 |
| 读取文件文本 | `GET /v1/runs/:runId/files/read` | `RunFileReadResponse` | 文本预览入口 |
| 下载文件 | `POST /v1/runs/:runId/download-tickets` + `GET /v1/downloads/:ticketId` | 下载票据 + 文件流/回源 | 当前前端已通过 SDK helper 发起下载 |
| 订阅实时 | `WS /ws/runs/:runId` 或 `GET /v1/runs/:runId/stream` | `ServerRealtimeMessage` | 优先 WS，回退 SSE |
