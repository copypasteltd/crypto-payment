## 13. 数据读写权威边界总表

| 对象 | 当前写入方 | 当前读取方 | 当前权威源 |
|---|---|---|---|
| run 聚合 | `RunsService` | API routes、realtime、file-access | `runsRepository` 本地 JSON |

| runtime 文件 | run-worker | bridge CLI / runtime | `<runRoot>/runtime/*` |
| secret 文件 | run-worker / bridge secret loader | bridge / Codex / MCP | `<runRoot>/secrets` |

## 14. 当前禁止越权访问边界表

| 边界 | 当前实现 |
|---|---|
| 文件浏览越界 | `file-access.ts` 通过 `path.relative(rootPath, candidate)` 拦截 |
| 文件下载目录下载 | 目录不可下载，抛 `FILE_PATH_INVALID` |
| 实时订阅错误 runId | WS path 与 payload runId 不一致时报错 |
| 容器内 secret 路径 | host/container 改写只映射到 `/workspace/secrets` |

## 15. 高耦合点总表

| 耦合点 | 当前位置 | 问题 | 后续收敛方向 |
|---|---|---|---|
| run 权威存储 | `app/api/modules/runs/repository.ts` | 文件存储与业务耦合 | `packages/db` |
| MCP 解析与物化 | `launch-plan.ts`、`container-runtime.ts`、`mcp-materializer.ts` | 能力逻辑分散 | `packages/mcp` |
| 凭证挂载逻辑 | `launch-plan.ts`、`secret-loader.ts`、`run-lifecycle.ts` | secret 规则分散 | `packages/credential` |
| 前端 VM 推导 | `dashboardData.ts`、`mobileData.ts`、adapter 层 | 静态数据与动态映射并存 | 统一 ViewModel 层 |
| 事件协议与展示协议 | `contracts/realtime.ts`、`socket-routes.ts`、SDK | 错误结构不完整 | 扩展结构化错误与 cursor |

## 17. 当前模块边界缺口总表

| 模块层 | 当前缺口 |
|---|---|
| API | 缺 auth、workspace ACL、quota、audit、DB repository |
| Worker | 缺真实 BullMQ consumer、Docker lifecycle、retry / DLQ |
| Bridge | 缺对象存储上传、稳定 resume、结构化错误码 |
| SDK | 缺结构化错误对象、SSE fallback 统一错误处理 |
| Frontend | 缺真实 Query 数据模型与静态数据脱钩 |
