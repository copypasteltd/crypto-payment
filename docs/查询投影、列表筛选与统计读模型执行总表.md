## 5. 当前 API / SDK 查询能力表

| SDK 方法 | 对应后端 | 当前能力 | 限制 |
|---|---|---|---|
| `listRuns()` | `GET /v1/runs` | 返回 `RunSnapshot[]` | 无分页、无筛选、无排序、无 summary |
| `getRun()` | `GET /v1/runs/:runId` | 返回完整单 run 快照 | 详情过重，未分 view |
| `listRunFileTree()` | `GET /v1/runs/:runId/files/tree` | 返回全量文件树 | 无 path scope、无分页、无 breadcrumb |
| `readRunFile()` | `GET /v1/runs/:runId/files/read` | 文本预览 | 只适合单文件 |
| `createRunsRealtimeClient()` | `ws /ws/runs/:runId` | run 详情实时推送 | 无列表级 summary 流 |

## 11. 分组逻辑后端化表

| 当前分组 | 当前前端判定 | 建议后端字段 |
|---|---|---|
| `Needs action` | `statusClass === warn/danger` 或 `needsApproval` | `attention_mode = todo` |
| `Running` | `statusClass === active` | `attention_mode = running` |
| `Output ready` | `resultReady && !needsApproval && statusClass !== active` | `attention_mode = done` |
| `Recent tasks` | live + static 合并后取前 3 | `recent_runs` query |

## 14. 切流顺序执行表

| 阶段 | 目标 | 说明 |
|---|---|---|
| Phase 1 | 补 `workspace summary` 与 `runs facets` | 先让顶部统计与筛选芯片脱离本地数组 |
| Phase 2 | 补 `run list query` 筛选参数 | 让列表分页、筛选、搜索走后端 |
| Phase 3 | 补 `workshop catalog query` | 工坊、服务、最近任务脱离静态目录 |

| Phase 5 | 补 `file browser query` | 文件页 path/breadcrumbs/query 真数据化 |

## 15. 阻塞项表

| 阻塞项 | 当前原因 | 影响 | 优先级 |
|---|---|---|---|
| API 无查询参数 | `listRuns()` 仅返回全量快照 | 双端列表无法正式扩展 | P0 |
| 无目录域 | 工坊和服务没有正式查询源 | 首页/工坊页无法切流 | P0 |
| 无 package list query | Creator 列表仍静态 | Creator 不能真数据化 | P0 |
| 无 facets query | 筛选芯片计数只能本地推导 | 列表交互不稳定 | P1 |
| 无 file browser query | 文件页 path 模型靠前端拼装 | 文件体验难扩展 | P1 |
