# 会话固化与只读分享实现说明

更新日期：2026-07-24

## 1. 目标

本轮更新覆盖微信小程序与 H5 的会话固化、继续对话、只读分享和固化记录分享。分享产物使用独立快照，源实例停止或释放后仍可读取。

## 2. 用户能力

| 能力 | 入口 | 执行结果 |
| --- | --- | --- |
| 建立检查点 | 任务详情 > 固化 > 建立检查点 | 固化当前已完成 Turn，实例保持运行，可继续对话 |
| 固化并结束 | 任务详情 > 固化 > 固化并结束 | 固化终结边界，验证完成后释放运行环境 |
| 分享当前会话 | 任务详情 > 分享 > 当前会话 | 将创建时刻之前的完整消息冻结为只读快照 |
| 分享固化记录 | 任务详情 > 分享 > 选择检查点或终结固化 | 按 Capture 边界生成可重复访问的只读快照 |
| 控制访问范围 | 分享配置 | 支持公开链接、工作区成员、指定用户 |
| 控制有效期 | 分享配置 | 支持 1 天、7 天、30 天和永久 |
| 管理分享 | 分享结果与历史 | 支持预览、微信转发、复制路径和撤销 |
| 阅读分享 | 会话只读页 | 展示消息、角色、时间、图片、视频和附件 |

## 3. 固化语义

| 模式 | Capture Mode | 会话状态 | Runtime 状态 | Creator 可用性 |
| --- | --- | --- | --- | --- |
| 检查点 | `checkpoint` | 保持可写 | 保持运行 | Capture 验证完成后可进入 Creator |
| 终结固化 | `terminal` | 进入终结流程 | 验证完成后释放 | Capture 验证完成后可进入 Creator |

Capture 只接受已经完成的 Turn。运行中的 Agent 回复不会进入本次边界。后续消息可以通过新的检查点单独固化。

## 4. 分享模型

| 字段 | 说明 |
| --- | --- |
| `sourceType` | `run` 或 `session_capture` |
| `sourceCaptureId` | 固化记录来源；当前会话分享时为空 |
| `boundaryTurnId` | Capture 或当前会话冻结时的 Turn 边界 |
| `boundaryMessageId` | 冻结快照最后一条消息 |
| `accessScope` | `public_link`、`workspace`、`invited_users` |
| `expiresAt` | 分享失效时间；为空时长期有效 |
| `includeSystemMessages` | 是否包含系统引导消息 |
| `includeFiles` | 是否复制并开放消息引用附件 |
| `status` | `active`、`expired`、`revoked` |

消息快照保存角色、正文、时间、原消息 ID 和文件关联。敏感字段、密钥模式、私钥块和 Run 绝对 target 路径在写入前执行脱敏。

## 5. 文件处理

1. 从消息附件、Markdown、HTML 和纯文本本地路径中提取图片、视频和一般附件引用。
2. 所有路径归一化到当前 Run target 目录，拒绝目录越界和外部绝对路径。
3. 创建分享时将可用文件复制到对象存储，并记录不可用文件状态。
4. 只读页通过短期 HMAC Grant 获取文件；受限分享的文件地址不暴露长期身份令牌。
5. 图片使用内联预览，视频支持 HTTP Range，一般附件通过小程序下载和系统文档打开能力读取。

## 6. 权限和审计

| 范围 | 未登录 | 同工作区用户 | 指定用户 | 创建者 |
| --- | --- | --- | --- | --- |
| 公开链接 | 允许 | 允许 | 允许 | 允许 |
| 工作区 | 拒绝 | 允许 | 仅同工作区时允许 | 允许 |
| 指定用户 | 拒绝 | 仅受邀时允许 | 允许 | 允许 |

每次只读页查看和文件访问写入独立审计记录。客户端网络标识经过 SHA-256 摘要后保存。撤销和过期返回稳定错误码，客户端展示明确失效状态。

公开读取接口使用独立响应投影，不返回源 Run ID、工作区 ID、Capture ID、创建者 ID、邀请名单和内部边界 ID。创建者管理接口保留这些字段，用于管理和审计。

## 7. API

| Method | Path | 作用 |
| --- | --- | --- |
| `POST` | `/v1/runs/:runId/conversation-shares` | 创建当前会话或 Capture 分享 |
| `GET` | `/v1/runs/:runId/conversation-shares` | 获取当前 Run 的分享记录 |
| `GET` | `/v1/conversation-shares/:shareId` | 创建者读取完整分享配置 |
| `GET` | `/v1/conversation-shares/public/:shareId` | 按分享权限读取只读快照 |
| `GET` | `/v1/conversation-shares/public/:shareId/files/:fileId` | 读取分享附件，支持短期 Grant |
| `POST` | `/v1/conversation-shares/:shareId/revoke` | 撤销分享 |
| `GET` | `/v1/conversation-shares/:shareId/access-audit` | 创建者读取访问审计 |

## 10. 验收标准

1. 检查点完成后当前实例继续运行并接受新消息。
2. 终结固化完成后实例进入释放流程。
3. 当前会话分享只包含分享创建时已经持久化的消息。
4. 固化记录分享严格停在 Capture 边界，不包含后续对话。
5. 源实例释放后，分享消息和已复制附件仍可读取。
6. 公开、工作区、指定用户三种权限均按矩阵执行。
7. 撤销和过期分享无法继续读取消息或附件。
8. 微信好友转发、朋友圈分享、路径复制和登录后路由恢复均可用。
9. 图片、视频、一般附件在微信小程序内按对应组件展示或打开。
10. TypeScript、后端分享测试、H5 构建和微信构建全部通过。
