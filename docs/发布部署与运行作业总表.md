# 灵办词元 发布部署与运行作业总表

## 1. 文档信息

| 字段 | 内容 |
|---|---|
| 文档名称 | 发布部署与运行作业总表 |
| 适用范围 | API、Worker、Bridge、Dashboard、Mobile H5、Runner Image |
| 统计日期 | 2026-07-07 |
| 文档目标 | 用作环境部署清单的执行补充，细化到作业、顺序、责任和验证口径 |

## 2. 部署作业分层总表

| 作业层 | 主要对象 | 当前执行方式 |
|---|---|---|
| 构建作业 | shared packages、backend、frontend | 本地命令 |
| 制品作业 | `dist/`、镜像 | 人工 |
| 配置作业 | `.env`、部署平台变量、secret | 人工 |
| 发布作业 | API / Dashboard / Mobile H5 / Worker / Bridge / runner | 人工 |
| 验证作业 | 健康检查、构建结果、联调 | 人工 |
| 回滚作业 | 切换制品版本或镜像标签 | 尚未标准化 |

## 3. 服务级运行作业矩阵表

| 服务 | 启动前条件 | 启动命令 / 作业 | 启动后验证 |
|---|---|---|---|
| API | 共享包与 API 已构建；端口可用 | `pnpm -C app/api start` | `/health`、`/v1/runs` 可访问 |
| Dashboard | API 地址已配置 | `pnpm -C app/dashboard build` 后由静态站点托管 | 页面可打开、可请求 API |
| Mobile H5 | API 地址已配置 | `pnpm -C app/mobile build:h5` 后由静态站点托管 | 页面可打开、工坊/任务可加载 |
| Run Worker | backend 构建完成 | 未来应由常驻进程 / job runner 启动 | 可处理 run 预处理作业 |
| Container Bridge | 运行时文件已生成 | `pnpm -C app/container-bridge start:runtime` 或容器入口 | `run.status.changed` 正常发出 |
| Runner Image | Docker 构建能力可用 | `docker build -f infra/docker/runner.Dockerfile` | 容器可启动且 entrypoint 正常 |

## 6. 当前缺口总表

| 领域 | 当前缺口 | 优先级 |
|---|---|---|
| 服务托管 | Worker / Bridge 尚未形成正式常驻托管模型 | P0 |
| 部署脚本 | 无统一部署脚本或 IaC | P1 |
| 运行作业自动化 | 当前全部依赖人工执行 | P1 |
| 发布验证自动化 | 缺少 smoke test 作业 | P1 |
