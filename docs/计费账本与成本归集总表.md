## 1. 文档信息

| 字段 | 内容 |
|---|---|
| 文档名称 | 计费账本与成本归集总表 |
| 适用范围 | `app/api`、`app/run-worker`、`app/container-bridge`、Dashboard 治理成本页、后续 billing 正式域 |
| 基准日期 | 2026-07-07 |
| 直接依据 | `docs/审计计费与配额总表.md`、`docs/风险与成本监控表.md`、`docs/观测指标与日志字段总表.md`、`app/dashboard/src/pages/creator/CreatorPage.tsx`、`app/api/src/modules/runs/routes.ts`、`packages/contracts/src/bridge.ts`、`packages/contracts/src/runtime.ts` |

## 9. 计量链路矩阵表

| 业务动作 | 用量记录 | 数量计算口径 | 定价来源 | 账本写入时机 |
|---|---|---|---|---|
| 创建 run | `active_runs + create_request` | 1 次 | run 启动费或免费 | 创建成功后 |
| 用户发送消息 | `message_requests`、后续 `model_tokens` | 按消息数、token 数 | 模型价格表 | 模型响应后 |
| 浏览器执行 | `browser_minutes` | 启动到结束分钟数 | 浏览器分钟价格表 | run 结束或周期心跳结算 |
| 第三方 MCP 调用 | `mcp_requests`、`mcp_bytes` | 调用次数/响应体积 | connector 价格表 | 调用完成后 |
| 文件上传 | `upload_bytes`、`upload_files` | 上传字节数和文件数 | 存储价格表 | 上传成功后 |
| 文件下载 | `download_bytes`、`download_files` | 下载字节数和次数 | 网络价格表 | 下载完成后 |
| 产物生成 | `artifact_storage_bytes` | 产物总字节数 | 存储价格表 | `artifact.ready` 后 |
| 审计导出 | `audit_export_jobs`、`audit_export_bytes` | 导出作业数和包大小 | 导出价格表 | 导出完成后 |
| 人工审批 | `manual_review_count` | 审批节点次数 | 审批服务费 | 审批完成后 |

## 14. 当前缺口与补齐顺序表

| 优先级 | 缺口 | 影响 | 补齐动作 |
|---|---|---|---|
| P0 | 无 `usage_record` 与 `cost_ledger` 正式表 | 无法形成真实成本治理 | 新建 billing 域与 repository |
| P0 | 无价格规则表 | 成本无法稳定复算 | 落地 `pricing_rule` |
| P0 | 无 provider 对账作业 | 无法核对第三方账单 | 新建 reconciliation job |
| P1 | 前端成本页仅静态语义 | 治理页无法反映真实费用 | 接入 `budget_snapshot` 与 `cost_ledger` |
| P1 | 下载、导出、MCP 调用未计量 | 外围成本漏记 | 在文件、导出、connector 层加 usage 写点 |
