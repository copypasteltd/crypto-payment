## 2. 当前事实矩阵

| 主题 | 当前实现 | 当前结论 | 当前缺口 |
|---|---|---|---|
| 工作区 root 展示 | Mobile 我的页展示 `currentWorkspace.root`，Dashboard 顶栏与说明展示 workspace root | 用户已经有工作区目录心智 | 仍是展示语义，不是正式文件树入口 |
| 任务文件页路径切换 | Mobile 文件页允许输入 `task.targetPath` 或 `currentWorkspace.root` 下路径；Dashboard 文件页允许在 `targetPath` 白名单内切换 | 双端都已有路径选择交互 | Mobile 的 workspace root 更像 UI 语义，后端并无对应文件树接口 |
| 任务文件读取边界 | API `resolvePathWithinTarget()` 只允许访问当前 run `targetPath` 内路径 | 后端当前安全边界清晰 | 无工作区共享目录读取域 |
| 我的资产 | Mobile 从 `combinedTasks.files` 扁平化派生最近资产 | 用户可在“我的”看到弱沉淀资产 | 无共享资产索引、无转存状态、无归档层级 |
| 共享目录引用 | 文档与 UI 已出现“财务共享目录”“共享目录引用”语义 | 产品语义已成立 | 缺真实 `workspace shared files` 数据源 |
| 运行目录结构 | Worker 已准备 `target/inputs/outputs/state/runtime/home/tmp/browser-profile/mcp/secrets/logs` | per-run 文件结构已完整 | 缺 workspace 级共享目录与长期资产目录 |
| 归档目录 | API seed `archive/` 目录，静态任务也频繁使用 `archive/*.json` | 归档语义已形成 | 无归档索引、无恢复、无保存策略 |

## 3. 当前路径模型矩阵

| 路径层级 | 当前来源 | 当前用途 | 当前限制 |
|---|---|---|---|
| `workspace.root` | `workspaceCatalog` / `workspaceEntries` | 工作区入口展示、路径提示 | 仅前端本地数据 |
| `run.targetPath` | `RunRecord.targetPath` | 当前实例主工作目录 | 是唯一正式文件访问边界 |
| `runRoot/inputs` | Worker `hostPaths.inputsPath` | 输入材料目录 | 未形成正式上传索引 |
| `runRoot/outputs` | Worker `hostPaths.outputsPath` | 最终结果目录 | 未形成独立结果域 |
| `runRoot/archive` | 当前多由 `targetPath/archive/` 表达 | 提示词、参数、审计归档 | 与 outputs/target 的责任边界未完全正式化 |
| `runRoot/logs` | Worker `hostPaths.logsPath` | 运行日志 | 前端无正式入口 |

## 8. 引用与复制边界矩阵

| 动作 | 定义 | 结果 | 适用场景 |
|---|---|---|---|
| 引用共享资产 | 只建立 `asset_reference`，不复制物理文件 | run 内看到同一份共享资产 | 大文件、受控只读材料 |
| 快照复制 | 复制到 run `inputs` 或 `targetPath` | run 获得独立副本 | 需要在 run 内修改 |
| 转存到我的 | 复制或重绑定到个人资产域 | 用户长期持有 | 结果留存、个人复用 |
| 归档 | 转入 archive 域并生成索引 | 长期审计保留 | prompt、审批、结果快照 |
| 恢复 | 从 archive 再次挂载或复制回可用目录 | 回放、重试、复盘 | 调试回放、纠错 |

## 12. 转存与归档执行矩阵

| 动作 | 输入 | 后端执行 | 输出 |

## 15. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无工作区文件树域 | 前端能展示 root，后端无 workspace 级文件接口 | 工作区共享资料无法正式使用 | P0 |
| 无共享资产索引 | 共享目录仅存在概念层 | 无法做复用、引用、治理 | P0 |
| Mobile 路径输入超出现实能力 | UI 允许以 workspace root 为范围输入路径 | 用户以为可以浏览 workspace，但实际仍是 task.files | P0 |
| 我的资产无转存记录 | 只展示最近文件 | 长期沉淀、追溯、清理都不可控 | P1 |
| 归档无正式对象 | 当前主要靠 `archive/` 目录约定 | 回放、审计、恢复链不完整 | P1 |
| 引用与复制未区分 | 当前没有结构化动作对象 | 大文件复用与写时隔离无法治理 | P1 |
