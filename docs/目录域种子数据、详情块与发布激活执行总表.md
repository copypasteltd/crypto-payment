## 12. 双端展示差异收敛表

| 差异项 | 当前 Dashboard | 当前 Mobile | 收敛建议 |
|---|---|---|---|
| owner 展示 | 多数无 owner 字段 | 工坊卡片显示 owner | 后端统一返回 `owner_label` |
| audience 展示 | 工坊详情主展示 | 通过 detail content 展示 | 都从 `workshop_details.audience_i18n` 读取 |
| risk 展示 | 服务启动台缺正式 risk 块 | 服务详情有 risk 文本 | 后端统一返回 `service_detail.risk_i18n` |
| connectors 展示 | 服务启动台只展示 auth 文本 | 服务详情展示 connector pills | 增加 `service_detail_blocks(connectors)` |
| launch flow 展示 | Dashboard 主要用概念描述 | Mobile 明确列步骤 | 后端统一返回 `launch_flow` |

## 13. 阻塞项表

| 阻塞项 | 当前原因 | 影响 | 优先级 |
|---|---|---|---|
| 目录种子未入库 | 目录信息仍在 TS 常量中 | Creator 发布无法驱动目录 | P0 |
| 详情块无正式对象 | outputs/connectors/launchFlow/boundary 无存储承载 | 服务详情无法真数据化 | P0 |
| release activation 未投影到目录 | 默认服务、默认版本仍写死 | 服务启动模板无法被发布链控制 | P0 |
| owner/audience/risk 字段口径不统一 | Dashboard 与 Mobile 来源不同 | 双端展示不一致 | P1 |

## 14. 完成判定表

| 判定项 | 满足条件 |
