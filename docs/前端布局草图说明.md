## 4. 结构性定稿点

### 4.1 用户侧主路径

```text
工坊 -> 服务 -> 任务 -> 结果
```

### 4.2 Dashboard 结构定稿

| 模块 | 定稿要求 |
|---|---|
| 一级导航 | 固定为 `工坊 / 实例 / Creator` |
| 左侧边栏 | 抽屉式，可折叠，可收起到图标态 |
| 工坊工作区 | 承载真实服务分发，不做空概览首页 |
| 实例工作区 | 左侧多实例列表，中部完整对话，右侧详情抽屉 |
| 实例子页 | `详情 / 文件 / 运行 / 审计` 属于实例内页，不上升为一级导航 |
| Creator 工作区 | 采用包视角组织工坊、服务、Session、版本、治理能力 |
| 技术信息暴露 | 容器、MCP、Trace、凭证绑定等信息默认折叠，按需展开 |

### 4.3 H5 / 小程序结构定稿

| 模块 | 定稿要求 |
|---|---|
| 一级导航 | 固定为 `工坊 / 任务 / 我的` |
| 工坊页 | 承载推荐工坊、企业工坊、最近使用、分类筛选 |
| 任务页 | 先展示多任务列表，支持分类、标签、搜索，点入后进入任务对话 |
| 任务详情 | 必须是完整对话工作面，支持持续对话、审批、上传、结果消费 |
| 文件页 | 从任务详情进入，支持路径面包屑、路径输入、目录切换、下载 |
| 我的页 | 承载个人资料、工作区切换、授权状态、通知、资产入口 |
| 当前空间 | 个人用户显示 `个人空间`；企业用户显示当前组织空间名称 |

## 5. 命名与术语约束

| 内部概念 | 用户侧表达 | 约束 |
|---|---|---|
| Session | 服务能力来源 / 版本来源 | 轻度用户侧不显式使用 `Session` |
| Run | 当前任务运行中 | 不作为一级导航名称 |
| Trace | 运行记录 | 仅在 Creator 或审计侧详细展开 |
| Workspace | 当前空间 / 工作区 | 放在 `我的` 页进行切换 |

## 6. 关键交互约束

| 交互点 | 约束 |
|---|---|
| 启动服务 | 点击启动后先创建任务实例，再进入对话 |
| 首条消息 | 系统自动注入“请问你需要我提供什么信息给你”式引导，由 Codex 主动提问 |
| 任务运行中 | 用户与 Codex 保持完整对话关系，过程信息通过消息卡片插入 |
| 审批处理 | 审批卡片内联到对话流，同时在列表态高亮 |
| 文件消费 | 文件生成后进入消息流、文件页、我的资产三处可达 |
| 折叠区 | 顶部摘要、运行信息、侧边信息均支持折叠 |
