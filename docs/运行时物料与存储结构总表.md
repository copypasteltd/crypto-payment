## 29. 当前代码对 MCP 物化的真实行为表

| 能力 | 当前真实行为 | 说明 |
|---|---|---|
| Catalog | 无内建 catalog | 代码未写死 `playwright/seedance/figma` 等条目 |
| 自动推导 | 无自动推导 | 当前不根据前缀自动补 URL 或 transport |
| 输入来源 | 完全依赖 `StartRunJobPayload.mcpBindings` | 绑定对象由上游直接提供 |
| 传输到配置 | `stdio` -> `local-process`；其他根据 `source` 转 `remote-managed` 或 `remote-unmanaged` | `container-runtime.ts` 与 `mcp-materializer.ts` 行为一致 |
| 认证注入 | `authMode=env/file` 时写入 `auth_env/auth_file` | 当前仅做直通物化 |
| 治理策略 | `networkPolicyRef`、`approvalRequired` 当前仅保留在 binding 数据中 | 尚未在运行时执行策略 |
