## 8. 字段级缺口总表

| 缺口类型 | 当前表现 | 直接影响 | 优先级 |
|---|---|---|---|
| Workshop 元数据缺口 | Dashboard/Mobile 主链已读 `run.catalogMetadata.workshopName`，历史 run 仍可能回退字符串推断 | 历史 run 与 demo 数据仍可能出现显示漂移 | P1 |
| Workspace 元数据缺口 | 当前通过前端 `normalize*WorkspaceId()` 映射 | 个人空间、企业空间、Creator 空间无法正式治理 | P0 |
| Creator 数据源缺口 | Creator 页已接 package/release/replay/gate/activation 与凭证/MCP 治理，治理详情表与审计计费域仍未正式化 | 治理闭环与正式审计/计费/配额仍未落地 | P0 |
| 运行时元数据缺口 | runtime image、mounts、notes 大量为前端静态文案 | 无法真实反映容器、镜像、MCP、凭证挂载状态 | P1 |
| 文件能力缺口 | 下载 URL 手工拼接，上传完全缺失 | 移动端材料提交、批量交付无法闭环 | P0 |
| 用户与权限缺口 | 前端无当前用户、成员、角色、授权态字段 | 无法切入正式多租户系统 | P0 |

## 11. 前端接口收口顺序表

| 阶段 | 动作 | 结果 |
|---|---|---|
| Phase 1 | 收敛 `auth/session`、`workspaces`、`workshops/services` 剩余静态 fallback | 前端目录层脱离静态数据 |
| Phase 2 | 补 `runs` 筛选分页与 facets | 任务/实例列表形成正式读链 |
| Phase 3 | 补 upload / download session / object storage 授权 | 文件输入输出闭环 |
| Phase 4 | 补 Creator 域 API | Dashboard Creator 切到真实后端 |
| Phase 5 | 收敛手工拼接 URL 与页面内字段推断 | SDK 成为唯一接口门面 |
