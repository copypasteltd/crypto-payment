## 2. 使用口径

| 维度 | 定义 |
|---|---|
| 批次 | 同一阶段可并行推进的一组交付 |
| 任务项 | 可被直接分配给单仓或单模块的执行单元 |
| 前置依赖 | 未完成前不建议进入开发或联调的上游事项 |
| 交付物 | 必须能被文件、代码、接口、脚本、运行证据证明的实际产物 |
| 验收口径 | 用于判定任务是否完成的最小强证据 |
| 状态口径 | 允许使用 `未开始` / `部分实现` / `半成品` / `进行中` / `已完成` 描述真实起点 |
