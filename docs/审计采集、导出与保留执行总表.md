## 6. 审计写入执行链总表

| 步骤 | 执行方 | 输入 | 动作 | 输出 |
|---|---|---|---|---|
| 1 | API/Bridge/Worker | 业务动作或运行事件 | 构造 `audit_entry` | 内存对象 |
| 2 | `AuditWriter` | `audit_entry` | 规范化字段、附加 `workspace_id/run_id/trace_id` | `audit_log` record |
| 3 | Repository | `audit_log` record | 事务写入正式表 | 持久化成功 |
| 4 | 异步投影 | 新增的高风险审计 | 推送通知、告警或治理计数 | 风险联动 |
| 5 | 查询/导出 | 按 scope/time/action 检索 | 聚合导出 | `audit_export_job` |

## 7. `audit_log` 执行字段矩阵

| 字段 | 作用 | 写入方 |
|---|---|---|
| `audit_log_id` | 审计主键 | `AuditWriter` |
| `workspace_id` | 工作区归属 | API/Bridge/Worker context |
| `scope_type` / `scope_ref_id` | 审计主体 | 业务层 |
| `action` | 动作名 | 业务层 |
| `result` | 成功/失败/拒绝/取消 | 业务层 |
| `risk_level` | 风险级别 | 策略映射器 |
| `actor_type` / `actor_user_id` | 操作者归属 | HTTP session / system |
| `actor_service` | 来源服务 | API/bridge/worker/dashboard/mobile |
| `run_id` | 实例关联 | 业务层 |
| `request_id` / `trace_id` | 排障关联 | middleware / telemetry |
| `payload_json` | 结构化附载 | 各采集点 |
| `occurred_at` | 发生时间 | 采集点 |
| `retention_class` | 保留级别 | 审计策略器 |

## 8. 审计导出状态机总表

| 状态 | 含义 | 可流转 |
|---|---|---|
| `queued` | 已创建任务，待消费 | `collecting/failed/cancelled` |
| `collecting` | 拉取日志、消息、审批、文件索引 | `masking/failed/cancelled` |
| `masking` | 按 profile 执行脱敏 | `packaging/failed` |
| `packaging` | 打包 `manifest + logs + summary` | `ready/failed` |
| `ready` | 导出包可下载 | `expired` |
| `failed` | 任一阶段失败 | 终态 |
| `cancelled` | 被用户取消 | 终态 |
| `expired` | 到期失效 | 终态 |

## 9. 脱敏 Profile 执行矩阵

| Profile | 适用对象 | 文本消息 | 路径 | 凭证引用 | 网络与来源 |
|---|---|---|---|---|---|
| `customer` | 交付给客户 | PII/敏感词脱敏 | 保留相对路径 | 仅保留 `credential_id` | IP 掩码、UA 摘要化 |
| `internal_ops` | 平台运维 | 原文可见 | 原路径可见 | 不暴露明文 | IP 掩码到网段 |
| `governance` | 治理与审核 | 原文可见 | 原路径可见 | 引用与 mount 信息可见 | 网络目标可见 |
| `compliance` | 法务/合规 | 原文可见 | 原路径可见 | 引用链完整可见 | 网络目标与源信息完整 |

## 11. 保留与冻结策略矩阵

| 对象 | 默认保留 | 冷存/归档 | 冻结条件 |
|---|---|---|---|
| `audit_log` | 热数据 90 天 | 之后转冷存 365 天 | 事故、投诉、法务保留 |
| `audit_export_job` | 元数据 365 天 | 包对象可单独过期 | 被标记为证据包 |
| `replay` 关联审计 | 90 天 | 可按 package 策略延长 | 发布争议/回滚调查 |
| 高风险 MCP 审计 | 180 天 | 冷存长期保留 | 网络违规、凭证事故 |
| 文件下载访问记录 | 90 天 | 可摘要化长期保留 | 数据外泄调查 |

## 14. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无正式 `audit_log` 表与 writer | 所有审计只停留在业务副作用 | 无法检索、导出、追责 | P0 |
| 文件访问未记审计 | 预览/下载不可追踪 | 企业合规不足 | P0 |
| 凭证与 MCP 未记审计 | 高风险能力不可留痕 | 安全治理不足 | P0 |
| 无 `audit_export_job` worker | 导出能力无法闭环 | 交付与审查不足 | P1 |
| 无 retention/hold 作业 | 生命周期不可治理 | 法务与事故场景不足 | P1 |
