## 4. `GET /v1/auth/session` 消费执行矩阵

| 维度 | 建议内容 |
|---|---|
| 接口职责 | 返回当前用户、当前设备会话、当前默认工作区、成员关系、偏好与最小能力摘要 |
| 调用时机 | Dashboard/H5 首屏启动、刷新后、工作区切换后、401 自动恢复后 |
| Query Key | `["auth","me"]` |
| 成功写入 | `currentUser`、`memberships`、`defaultWorkspaceContext`、`abilitySummary` |
| 失败处理 | `401` 跳登录；`403` 跳受限页；网络失败进入离线/重试提示 |
| Dashboard 消费点 | `AppProviders` 级 bootstrap、`DashboardShell` 顶栏、Creator 权限守卫 |
| H5 消费点 | `app.tsx` 级 bootstrap、工坊页入口、我的页面、任务详情前置校验 |
| 与现有 store 关系 | 本地 `currentWorkspaceId` 只作为恢复候选值，最终以服务端 membership 判定为准 |

## 5. 会话刷新执行矩阵

| 场景 | 触发条件 | 前端动作 | 后端动作 | 结果 |
|---|---|---|---|---|
| 首屏访问且 access 已过期 | 页面刷新、重新打开浏览器 | 先尝试 `POST /v1/auth/refresh` | 校验 refresh token / cookie，返回新 access token | 无感恢复会话 |
| API 返回 `401` | access 过期或失效 | 单飞刷新，请求排队 | 签发新 access token 或拒绝 | 成功则重放请求，失败则登出 |
| 切换工作区后能力变更 | 角色或工作区上下文变化 | 强制刷新 access token | 重新编码 `workspace_context_version` | 新 token 权限与上下文一致 |
| 风险设备或会话撤销 | 用户主动登出、管理员撤销 | 清空本地缓存，关闭 realtime | 后端使 refresh 会话失效 | 全端回到登录态 |

## 6. 工作区切换执行矩阵

| 步骤 | 执行方 | 输入 | 动作 | 结果 |
|---|---|---|---|---|
| 1 | 前端 | 目标 `workspace_id` | 发起 `POST /v1/workspaces/switch` | 切换请求发出 |
| 2 | API | 当前用户 session + 目标 workspace | 校验 membership、状态、角色与是否冻结 | 切换合法性 |
| 3 | API | 校验通过 | 返回 `workspace_context`、`workspace_switch_ticket`、必要时新的 access token | 服务端上下文切换完成 |
| 4 | 前端 | 切换响应 | 更新 store 中 `currentWorkspaceId` | UI 命名空间切换 |
| 5 | 前端 | 新工作区上下文 | 失效目录、run、Creator、文件、草稿命名空间 | 跨空间缓存被清理 |
| 6 | 前端 | 新工作区上下文 | 重连 run realtime、重新加载列表 | 数据面刷新 |

## 12. 当前阻塞项总表

| 阻塞项 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 缺少统一 401 重放队列 | 当前只在 bootstrap 流程自动 refresh | 页面内长会话稳定性不足 | P1 |
| 工作区成员/偏好深域未落地 | 当前只有 `session/workspaces/switch` 基础链路 | 无法形成完整企业空间治理 | P0 |
| 草稿未按正式 workspace context version 隔离 | 当前主要按 `workspaceId` 命名空间缓存 | 工作区重命名或迁移后的缓存治理不足 | P1 |
| 无统一刷新策略 | 没有单飞刷新、请求重放、401 收敛 | 正式长会话不可用 | P1 |
| 草稿未按工作区正式分桶 | 当前只按实例或任务 id 保存 | 跨工作区存在命名污染风险 | P1 |
