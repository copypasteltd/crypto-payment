## 5. 当前判断

1. 双前端、后端、worker、bridge 五个仓库都已经脱离纯原型阶段，主干代码与模块边界已成型。
2. 当前最成熟的是 `agent-workshop-backend` 和 `agent-workshop-dashboard`。
3. 当前最大的系统缺口集中在三类能力：正式 billing/cost ledger、更多执行点的 quota 接入、真实容器运行链路的生产化。
4. 移动端 quota 已从只读占位推进到真实 API 接线，当前已具备工作区级 quota 摘要、run 内 quota 审批详情和对话内 approve/reject 闭环。
5. `packages/*` 仍是共享工作区层，后续是否拆仓应由发布策略和团队协作边界决定。
