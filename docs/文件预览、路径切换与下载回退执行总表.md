## 2. 当前事实矩阵

| 主题 | 当前证据 | 当前结论 | 当前缺口 |
|---|---|---|---|
| 文件树接线 | 双端都调用 `listRunFileTree()` | 主链已接通 | 缺对象存储层与下载授权会话 |
| 文本预览接线 | 双端已切到 `previewRunFile()` | 文本预览可用 | 长文本分段与更细错误语义仍不足 |

| 后端读取限制 | `MAX_TEXT_BYTES = 256 * 1024`，目录不可读、目录不可下载 | 权限边界已存在 | 前端缺显式预览级别与失败原因分类 |

## 7. 路径规则矩阵

| 主题 | Dashboard 当前规则 | Mobile 当前规则 | 正式要求 |
|---|---|---|---|
| 根路径 | 必须位于当前实例 `targetPath` 内 | 允许位于 `task.targetPath` 或 `currentWorkspace.root` 内 | 统一收敛到后端返回的 allowlist |
| 路径标准化 | `normalizeDirectoryPath()` + `resolveDirectoryPath()` | `trim()` 后直接判断前缀 | 双端统一使用 path allowlist 适配器 |
| 非法路径反馈 | inline `pathError` | toast “路径需位于当前工作区内” | 统一结构化错误码映射 |
| 目录读取 | 仅列目录，不可直接预览 | 同左 | 保持 |
| 越界访问 | 前端限制 + 后端 `FILE_PATH_INVALID` | 前端限制 + 后端 `FILE_PATH_INVALID` | 保持后端权威 |

## 8. 预览能力与降级矩阵

| 场景 | 当前行为 | 当前问题 | 正式要求 |
|---|---|---|---|
| 文本小文件 | 直接显示全文 | 基础可用 | 保持 |
| 文本大文件 | 显示前 256KB 并追加截断提示 | 无“继续下载完整文件”结构化状态 | 增加 `preview_truncated` 状态 |
| 二进制文件 | 显示“更适合下载查看” | 无法区分图片/PDF/视频/权限失败 | 按 MIME 分类为可预览或下载回退 |
| 静态 fallback 文件 | 显示静态预览说明 | 容易与真实文件混淆 | 明确 `reference data` 标识 |
| 文件不存在 | `readRunFile()` 返回 `null` 后显示下载提示或空预览 | 错误语义混淆 | 区分 `not_found / not_previewable / no_permission / backend_failed` |

## 9. 后端能力约束矩阵

| 后端能力 | 当前实现 | 对前端影响 |
|---|---|---|
| 路径边界 | `resolvePathWithinTarget()` 保证不越出 `targetPath` | 前端必须围绕 allowlist 设计 |
| 目录不可读 | `FILE_PATH_INVALID` | 预览按钮不能对目录生效 |
| 下载不可对目录生效 | `FILE_PATH_INVALID` | 文件列表需区分文件与目录 |
| 读取上限 | `256KB` | 大文件预览只能摘要化 |
| MIME 推断 | 仅少量文本/PDF/图片扩展映射 | 前端需等后端补完整 MIME 能力 |
| 图片 MIME | 当前落到 `application/octet-stream` | 无法驱动图片专用预览 |

## 10. SDK 与接口缺口表

| 主题 | 当前状态 | 影响 | 优先级 |
|---|---|---|---|
| 下载方法 | `api-sdk` 已封装 `getRunFileDownloadUrl()` | 基础文件下载已收口 | P1 |

## 11. 前端 ViewModel 缺口表

| 目标字段 | 当前状态 | 当前问题 |
|---|---|---|
| `previewable` | 当前隐含在说明文案中 | 组件无法基于布尔语义渲染 |
| `downloadable` | 当前隐含为“有按钮即能下载” | 无权限态无法显式表达 |
| `mimeType` | 当前未进前端 VM | 无法选择预览组件 |
| `source` | 当前仅靠静态 fallback 文案区分 | 真实文件与参照文件不易区分 |
| `previewState` | 当前无 | 无法表达 `loading/truncated/not_supported/error` |

## 12. 错误与回退矩阵

| 错误场景 | 当前行为 | 正式行为 |
|---|---|---|
| `FILE_PATH_INVALID` | Dashboard inline note / Mobile toast | 页面内统一错误卡片 + 可恢复动作 |
| `FILE_NOT_FOUND` | 当前多落为无预览 | 显示文件已失效或已移动 |
| `readRunFile()` 失败 | 返回 `null` | 区分网络失败、权限不足、类型不支持 |
| 下载失败 | Mobile toast，Dashboard 无失败态 | 统一 toast/banner + 重试 |
| 预览截断 | 仅文本追加一句提示 | 提供“下载完整文件” CTA |

## 13. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 文件预览能力覆盖仍不完整 | 图片/PDF 已有基础工作面，表格/视频/Office 仍未形成专用工作面 | 文件消费能力仍不足 | P0 |
| 下载尚未全域统一 | 文件页已收口到 SDK，bundle/export 等文件场景仍未统一 | SDK 仍未成为全域文件接入层 | P1 |
| 双端路径规则不一致 | Dashboard 只看 `targetPath`，Mobile 还放宽到 workspace root | 容易形成行为漂移 | P1 |
| 错误语义混淆 | `null` 同时代表不支持预览、接口失败、无权限 | 用户与调试都不友好 | P1 |
| ViewModel 无显式预览字段 | 组件层无法稳定收敛状态 | 后续组件化困难 | P1 |
