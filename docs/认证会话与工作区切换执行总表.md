## 3. 会话载体执行矩阵

| 载体 | 终端 | 建议内容 | 生命周期 | 主要用途 |
|---|---|---|---|---|
| `access_token` | Dashboard、H5、后续小程序 | `user_id`、`session_id`、`workspace_context_version`、`role_version` | 5-30 分钟 | API 鉴权 |
| `refresh_token` | Dashboard、H5 | 仅会话续期所需最小信息 | 7-30 天 | 刷新 access token |
| `device_session_id` | Dashboard、H5、小程序 | 设备级会话标识 | 与 refresh token 同周期 | 安全中心和会话撤销 |
| `workspace_switch_ticket` | Dashboard、H5、小程序 | 当前切换请求摘要 | 秒级 | 切换工作区时确保读写一致 |
| `internal_service_token` | API、Worker、Bridge | 服务身份、环境、最小权限范围 | 可轮换 | 内部服务调用 |

## 6. 工作区切换执行链路矩阵

| 步骤 | 执行方 | 输入 | 动作 | 输出 |
|---|---|---|---|---|
| 1 | 前端 | 目标 `workspace_id` | 用户点击切换工作区 | 切换请求 |
| 2 | API | 当前 session + 目标 workspace | 校验 membership 是否存在且状态为 active | 切换合法性 |
| 3 | API | 切换合法性通过 | 生成 `workspace_context`、可选新 `access_token`、`workspace_switch_ticket` | 切换结果 |
| 4 | 前端 | `workspace_context` | 更新本地 store、清空旧工作区缓存、重拉目录和实例列表 | 新上下文生效 |
| 5 | 前端 | 新工作区上下文 | 重新连接 realtime、重拉文件和 Creator 目录 | 页面完成刷新 |

| Run 列表缓存 | Dashboard、H5 | 重新请求 `/v1/runs` |

## 10. 内部服务鉴权执行矩阵

| 调用方向 | 当前状态 | 正式建议 | 关键字段 |
|---|---|---|---|
| Bridge -> API | 当前仅内部路由，无正式服务鉴权 | 使用 `internal_service_token` + `bridge_id` + `run_id` | `service_name`、`env`、`bridge_id` |
| Worker -> API | 当前嵌入式调用 | 使用服务 token 和最小权限 claim | `service_name`、`job_type` |
| API -> Worker | 当前本地 orchestrator | 统一 job envelope 和签名校验 | `job_id`、`issued_at` |

## 11. 会话安全动作矩阵

| 动作 | 触发条件 | 执行结果 |
|---|---|---|
| 刷新 access token | access 即将过期 | 返回新 access token |
| 撤销当前会话 | 用户主动退出 | 当前 session 失效 |
| 撤销其他设备会话 | 用户在安全中心操作 | 指定 `device_session_id` 失效 |
| 强制工作区重切 | 成员角色变更 | 旧 `workspace_context_version` 作废 |
| 强制重新登录 | 账号冻结、密码修改、MFA 异常 | 全部 refresh token 作废 |

## 12. 当前缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无真实 auth 域 | 双端仅本地 store | 无法进入生产多用户模式 | P0 |
| 无工作区切换服务端上下文 | 仅前端切换字符串 | 无法形成正式授权边界 | P0 |
| 无 session revoke | 无安全中心与设备会话管理 | 账号安全能力不足 | P1 |
| 无内部服务 token | Bridge/Worker 到 API 缺少正式签名 | 内部调用不可正式治理 | P1 |

## 15. 会话/工作区收口顺序表

| 阶段 | 动作 | 收口结果 |
|---|---|---|
| Phase 1 | 落地 access/refresh/session 基础模型 | 前端有真实登录态 |
| Phase 2 | 落地 memberships/workspace context/switch API | 工作区切换有服务端权威语义 |
| Phase 3 | 落地 revoke/device session/internal service token | 会话安全与内部鉴权成型 |
| Phase 4 | 落地 role-based guard 与跨端恢复 | Creator/治理页可正式开放 |
