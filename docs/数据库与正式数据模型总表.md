# 灵办词元 数据库与正式数据模型总表

## 1. 文档信息

| 字段 | 内容 |
|---|---|
| 文档名称 | 数据库与正式数据模型总表 |
| 文档类型 | Database & Formal Data Model Matrix |
| 适用范围 | `agent-workshop` 全工作区 |
| 基准日期 | 2026-07-08 |
| 关联文档 | `docs/后端设计文档.md`、`docs/工程状态总表.md`、`docs/接口与契约字段总表.md`、`docs/运行时物料与存储结构总表.md` |
| 使用目的 | 将正式数据库层的域划分、核心表、关键字段、关系、索引、保留策略和当前落地缺口统一表格化 |

## 2. 来源口径说明表

| 口径 | 含义 |
|---|---|
| `代码已实现` | 当前仓库中已有代码、schema 或存储结构可直接验证 |
| `设计已明确` | 已在现有设计文档中明确写出，但当前代码未落地 |
| `设计推导` | 基于产品需求、前端需求、后端设计和现有代码关系推导出的正式建模建议 |

## 3. 当前数据层现实与目标差距表

| 维度 | 当前现实 | 目标状态 | 来源口径 |
|---|---|---|---|
| run 元数据 | 本地 JSON 文件 | PostgreSQL 权威主库 | 代码已实现 + 设计已明确 |
| 事件日志 | 本地 JSONL 文件 | PostgreSQL 审计索引 + 对象存储 trace 包 | 代码已实现 + 设计推导 |
| 文件产物 | 本地目录与 API 直读 | 对象存储 + 元数据表 | 代码已实现 + 设计已明确 |
| session 资产 | 仅有设计与前端概念 | PostgreSQL 元数据 + S3 session pack | 设计已明确 |
| 凭证治理 | env/file 注入基础 | Vault/KMS + Credential Broker + 审计表 | 代码已实现 + 设计已明确 |
| MCP 治理 | 绑定字段与 runtime 物化基础 | MCP 注册表、绑定表、风险策略表、审计表 | 代码已实现 + 设计已明确 |
| 权限治理 | 当前无正式表 | 用户、工作区、成员、角色、策略、审计 | 设计已明确 |
| 计费与配额 | 当前无正式表 | 成本账本、预算策略、配额策略、超限记录 | 设计推导 |
