## 6. 漏斗定义总表

| 漏斗 | 目标人群 | 步骤顺序 | 核心判定 |
|---|---|---|---|
| 轻度用户启动漏斗 | H5 / 小程序轻度用户 | `workshop_impression -> workshop_click -> service_detail_view -> run_launch_click -> run_created_success -> codex_prompt_visible -> conversation_message_sent` | 判断“看到就用”是否成立 |
| 结果消费漏斗 | 已有运行实例用户 | `run_created_success -> approval_requested? -> artifact.ready 对应可视 -> file_download_click / result_rerun_click` | 判断结果是否真正被消费 |
| 搜索分发漏斗 | 搜索入口用户 | `search_submit -> search_result_click -> service_detail_view -> run_launch_click` | 判断搜索是否有效提升转化 |
| 失败恢复漏斗 | 遭遇失败或中断的用户 | `conversation_message_failed / realtime_degraded -> retry -> conversation_message_sent / run_created_success / file_download_click` | 判断恢复机制是否可用 |

## 7. 漏斗口径与分群表

| 维度 | 口径 |
|---|---|
| 用户维度 | `user_id` 有值时按登录用户；无值时按 `device_id + session_id` |
| 工作区维度 | 所有核心漏斗必须带 `workspace_id` |
| 服务维度 | 工坊、服务、任务相关事件必须带 `workshop_id`、`service_id` |
| 运行维度 | 任务创建后必须带 `run_id`，后续对话/文件/审批都挂接到 `run_id` |
| 时间窗 | 启动漏斗默认 24 小时归因；结果消费漏斗默认 7 天归因 |
| 去重策略 | 曝光按 `surface + entity_id + viewport_session` 去重；点击/发送/下载按 `event_id` 去重 |

## 11. 客户端采集链路总表

| 步骤 | Dashboard | Mobile | 正式要求 |

## 12. 上报与重试策略表

| 场景 | 策略 |
|---|---|
| 曝光事件 | 进入可视区后延迟 300~500ms 采集，避免快速滚动噪声 |
| 点击事件 | 同步入队，异步批量上报 |
| 页面卸载 | H5 使用 `sendBeacon`；Taro H5/小程序使用 `flush + best effort` |
| 网络失败 | 入本地失败队列，指数退避重试 |
| 重复点击 | 以 `event_id` 去重；必要时附加 `dedupe_key` |
| 重复曝光 | 同一可视 session 内对同一实体只记一次 |
| WS 失败回退 SSE | 同时打 `realtime_degraded`，并记录 `fallback_to=sse` |

## 13. 埋点与审计边界表

| 主题 | 产品埋点 | 审计事件 |
|---|---|---|
| 目的 | 分析转化、使用习惯、体验质量 | 合规留痕、责任追踪、不可抵赖 |
| 精度 | 允许聚合、抽样、延迟处理 | 要求完整、有序、可追溯 |
| 载荷 | 尽量轻量，不包含敏感正文 | 可记录更完整上下文，但需脱敏 |
| 对话正文 | 默认不上报全文 | 审计域按保留与脱敏策略处理 |
| 凭证 / 密钥 | 不进入产品埋点 | 审计域仅记录引用与治理动作，不记录明文 |

## 14. 隐私与脱敏约束表

| 对象 | 处理要求 |
|---|---|
| 用户自由输入文本 | 默认不上报全文，只记录长度、语言、是否为空、是否包含附件 |
| 文件路径 | 对展示友好的业务目录可保留相对路径；绝对路径建议哈希或截断 |
| 查询词 | 默认保留原词，但企业空间应支持脱敏和停用词策略 |
| 凭证相关动作 | 仅上报 `credential_id`、`provider`、`action`，不记录内容 |
| 结果包文件名 | 可记录扩展名、类型、大小桶；敏感文件名需可哈希 |

## 15. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无统一事件命名 | 只有需求清单，没有代码常量 | 双端难以对齐 | P0 |
| 无前端埋点 SDK | 页面没有 `trackEvent()` | 事件无法规模化接入 | P0 |
| 无本地队列与失败重试 | 页面关闭或弱网会丢事件 | 数据不稳定 | P0 |
| 无曝光采集模型 | 只有点击能人工推断 | 无法还原真实分发效率 | P1 |
| 无漏斗定义和归因口径 | 指标定义停留在需求层 | 报表不可比 | P1 |
| 无运行质量埋点 | WS/SSE 回退缺少行为证据 | 无法定位体验劣化 | P1 |
