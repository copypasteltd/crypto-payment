|---|---|

| 适用范围 | 从当前 file-backed 原型迁移到 PostgreSQL、对象存储、正式事件存储体系 |

| 前端静态工坊/Creator 数据 | `app/dashboard/src/data/*`、`app/mobile/src/data/*` | TS 常量 | PostgreSQL `workshops/services/packages` |

## 4. 批次执行脚本矩阵

| 脚本 | 输入 | 输出 | 核心职责 |
|---|---|---|---|
| `migrate-runs.ts` | `runs/*.json` | `runs`、`run_messages`、`approvals`、`run_artifacts` | 导入 Run 聚合核心数据 |
| `migrate-events.ts` | `events/*.jsonl` | `run_events` | 导入事件流 |
| `index-run-files.ts` | Run root 扫描结果 | `run_files` | 建立文件索引 |

| `verify-migration.ts` | 数据库、对象存储、原始文件 | 校验报告 | 生成一致性结论 |

## 5. 批次校验矩阵

| 校验项 | 校验方式 | 通过标准 |
|---|---|---|
| Run 数量一致 | JSON 文件数 vs `runs` 表行数 | 完全一致 |
| Message 数量一致 | 聚合消息总数 vs `run_messages` 行数 | 完全一致 |
| Approval 数量一致 | 聚合审批总数 vs `approvals` 行数 | 完全一致 |
| Artifact 数量一致 | 聚合产物总数 vs `run_artifacts` 行数 | 完全一致 |
| Event 数量一致 | JSONL 行数 vs `run_events` 行数 | 完全一致 |
| 文件索引一致 | 目录扫描结果 vs `run_files` | 核心路径全部命中 |
| 对象上传完整 | 本地文件数 vs 对象存储对象数 | 核心文件全部上传 |
| 最终状态一致 | JSON `run.status` vs `runs.status` | 完全一致 |

## 6. 切流 Gate 矩阵

| Gate | 进入条件 | 通过条件 | 失败动作 |
|---|---|---|---|
| `schema-ready` | 正式表结构与索引部署完成 | 建表成功且 smoke query 通过 | 停止迁移 |
| `history-import-ready` | 批次 1-4 执行完 | 行数、状态、一致性校验通过 | 修复脚本后重跑 |
| `object-storage-ready` | 批次 5 执行完 | 关键对象可下载可预览 | 回退本地文件下载 |
| `dual-write-ready` | API 已具备双写能力 | JSON 与 PostgreSQL 一致性达标 | 维持旧写链 |
| `read-switch-ready` | 新 repository 可灰度读 | 灰度环境读结果无偏差 | 切回 JSON 读链 |

## 7. 切流顺序矩阵

| 顺序 | 读写链路 | 建议动作 |
|---|---|---|
| 1 | 写链路 | 先上 PostgreSQL 双写，仍以 JSON 为主读 |
| 2 | 列表与详情读链 | 灰度切 PostgreSQL 读 |
| 3 | 事件 backlog 读链 | 切到正式事件表或正式事件总线 |
| 4 | 文件索引读链 | 文件树、stat、read 优先查索引 |
| 5 | 下载链路 | 优先签名对象下载，缺失时回退本地下载 |

## 8. 回滚动作矩阵

| 回滚点 | 回滚方式 | 影响范围 |
|---|---|---|
| Run 读链切换后 | 切回 JSON repository | API 列表、详情、审批、消息 |
| 事件读链切换后 | 切回 JSONL backlog | Realtime backlog |
| 对象下载切换后 | 切回本地文件下载 | 文件与产物下载 |
| 工坊/Creator 元数据切换后 | 切回前端静态数据源 | Dashboard、H5 目录页 |

## 9. 风险矩阵

| 风险 | 触发条件 | 影响 | 缓解动作 |
|---|---|---|---|
| JSON 脏数据 | 早期样例结构不一致 | 导入失败或字段丢失 | 先跑 schema lint，再导入 |
| 事件顺序错乱 | JSONL 写入存在竞态 | replay 与审计偏差 | 导入时按事件时间和序号重建 |
| 文件索引缺失 | 历史 run 目录不完整 | 文件页展示缺口 | 标记缺失并保留人工复核清单 |
| 对象上传中断 | 大文件或网络问题 | 上传不完整 | 支持断点重试与结果清单复跑 |
| 双写漂移 | 新旧写链不一致 | 切流风险 | 建立逐批校验报告 |
