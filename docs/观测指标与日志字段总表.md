# 灵办词元 观测指标与日志字段总表

## 1. 文档信息

| 字段 | 内容 |
|---|---|
| 文档名称 | 观测指标与日志字段总表 |
| 适用范围 | API、Run Worker、Container Bridge、Dashboard、Mobile |
| 统计日期 | 2026-07-08 |
| 当前事实 | API 正式 logger 关闭；Bridge / Worker 仅有基础 stdout/stderr 与 JSONL 事件落盘；前端无统一埋点体系 |
| 文档目标 | 统一说明当前可观测信号、建议日志字段、建议指标目录、告警与仪表板设计、当前缺口 |

## 2. 当前观测信号来源总表

| 层 | 当前信号来源 | 当前形态 | 当前状态 |
|---|---|---|---|
| API | `console.log` / `console.error`、HTTP 响应、JSONL event bus | 文本输出 + 文件 | 基础 |
| Realtime | `runEventBus` 内存事件 + JSONL 回放 | 事件流 | 中 |
| Run Worker | runtime 物料文件、Bridge stdout/stderr log | 文件 | 基础 |

| Dashboard | React Query 缓存状态、WS/SSE 连接状态 | 浏览器内状态 | 基础 |
| Mobile | React Query 缓存状态、WS/SSE 连接状态 | 浏览器/小程序内状态 | 基础 |

## 13. 告警规则建议表

| 告警名 | 触发条件 | 告警等级 |
|---|---|---|
| API 5xx 升高 | 5 分钟内 5xx 比例超过阈值 | P1 |
| Realtime 建连失败率升高 | WS/SSE 连接成功率连续下降 | P1 |
| Run 失败率升高 | `runs_failed_total / runs_created_total` 超阈值 | P1 |
| Bridge 无心跳 | 运行中 run 超过阈值时间未出现 `heartbeat` | P1 |
| 文件读取异常升高 | `FILE_NOT_FOUND` / `FILE_PATH_INVALID` 激增 | P2 |
| 产物长时间未完成 | 运行中 run 超时仍无 `artifact.ready` | P2 |
