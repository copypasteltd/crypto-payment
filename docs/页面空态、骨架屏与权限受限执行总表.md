## 4. 正式页面状态目录表

| 状态 | 含义 | 最低字段 |
|---|---|---|
| `loading` | 首次加载中 | `scope/message/skeleton_profile` |
| `partial_ready` | 缓存可读，增量刷新中 | `stale_at/source/cache_age` |
| `empty` | 数据正常返回但为空 | `reason/cta` |
| `error` | 请求或处理失败 | `error_code/message/retryable` |
| `forbidden` | 无权限访问 | `resource_scope/request_access_action` |
| `offline` | 网络或 realtime 断连 | `transport/ws_status/last_success_at` |
| `degraded` | 功能可读但不可写 | `blocked_actions/readonly_reason` |

## 9. 错误态矩阵

| 场景 | 当前行为 | 正式行为 |
|---|---|---|
| Query 拉取失败 | 多数 `catch -> null/[]` | 显示 `error state`，保留缓存内容和重试 |
| 实时断连 | 连接状态弱表达 | 连接横幅 + 自动重连 + 手动重试 |

## 14. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无统一 page-state 模型 | 各页局部 `if (!data)` 分支自行处理 | 状态语义不一致 | P0 |
| 骨架屏缺失 | 大多数页面直接等待数据 | 首屏与切换体验粗糙 | P0 |
| 权限受限页缺失 | auth/RBAC 未接入时无 UI 收口 | 正式接入后风险高 | P0 |
| Query 失败大量回退空数组/空对象 | 空态与错误态混淆 | 难排障，误导用户 | P1 |
| 断连态不统一 | 对话和文件链无统一 banner | 实时体验不稳定 | P1 |
