## 8. 本地 bridge 启动执行矩阵

| 步骤 | 当前实现 | 输出 |
|---|---|---|
| 1 | `allocatePort()` 动态分配控制端口 | `controlPort` |

## 9. runner 镜像入口执行矩阵

| 步骤 | 入口脚本行为 | 当前意义 |

## 11. 终态收口执行矩阵

| 场景 | 当前行为 | 当前输出 |
|---|---|---|
| `run.failed` 事件 | bridge CLI `handleEvent()` 触发 `shutdown(1)` | 进程退出码 `1` |
| `run.status.changed(SUCCEEDED)` | `shutdown(0)` | 正常退出 |
| `run.status.changed(FAILED/CANCELLED)` | `shutdown(1)` | 异常/取消退出 |
| 本地 `stop()` | `child.kill("SIGTERM")` | 等待 completion |
| API cancel | `bridgeRegistry.dispatch(cancel)` + `runOrchestrator.requestStop()` | 状态更新 + 运行停止 |

## 12. 清理与保留执行矩阵

| 对象 | 当前处理 | 正式要求 |
|---|---|---|
| 本地 bridge 子进程 | 可 `SIGTERM` 结束 | 终态必须保证 stop |
| 容器实例 | 当前未真正创建 | `docker stop/rm` 或 Pod delete |
| `logs/` | 保留在 runRoot | 采集后归档 |
| `runtime/` | 保留 | 保留关键证据，清理非必要缓存 |
| `secrets/` | 当前保留在 runRoot | 终态清除或加密封存 |
| `browser-profile/` | 当前保留 | 按策略保留最短必要周期 |
| `outputs/` | 保留 | 归档到对象存储并建索引 |

## 13. 正式 Docker/K8s 执行矩阵

| 阶段 | Docker 模式 | K8s 模式 |
|---|---|---|
| 启动 | `docker create --rm ...` -> `docker start -a` | 创建 `Job` / `Pod` |
| 健康探测 | HTTP `/health` 或进程检查 | readiness / liveness probe |
| 控制面 | localhost control server 或 sidecar | service / exec / sidecar |
| 日志采集 | `docker logs` + volume | pod logs + sidecar shipping |
| 终止 | `docker stop` -> `docker rm` | delete pod/job |
| 标签/查询 | container labels | pod labels / annotations |

## 14. 当前阻塞项总表

| 阻塞项 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| Docker daemon 实机联调未完成 | 代码已落地但当前机器未验证真容器 | 多用户真实隔离仍缺现场证据 | P0 |
| secret/profile 清理策略未完成 | runRoot、secret、browser profile 仍可能残留 | 资源与安全风险 | P0 |
| 挂载读写边界偏宽 | inputs/runtime/mcp 多为可写 | 隔离面过宽 | P1 |
| bridge 启动失败分类不足 | 超时、端口、secret、MCP 错误未分层 | 运维处理困难 | P1 |
