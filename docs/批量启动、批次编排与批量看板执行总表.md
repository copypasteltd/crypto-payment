## 8. 批量调度执行矩阵

| 阶段 | API/Worker 行为 | 输出 |
|---|---|---|
| `draft` | 保存导入文件与解析结果 | 待确认批次 |
| `validated` | 字段校验、配额校验、权限校验通过 | 可启动批次 |
| `queued` | 将每个 `batch_run_item` 推入调度队列 | 排队中 |
| `running` | Worker 按并发上限消费 item，创建真实 run | 运行中 |
| `partial_failed` | 部分项失败 | 支持失败重跑 |
| `completed` | 所有项完成或终止 | 生成批次汇总 |
| `cancelled` | 用户或策略中止剩余项 | 部分结果保留 |

## 11. 失败重跑执行矩阵

| 场景 | 当前状态 | 正式动作 |
|---|---|---|
| 某一行参数错误 | 无 | 修正行数据后重建 `batch_run_item` |
| 外部 API 失败 | 无 | 允许按错误类型筛选重跑 |
| 配额审批待确认 | 无 | 先审批，再继续剩余项 |
| 部分成功部分失败 | 无 | 生成 `batch_retry_job`，只重跑失败集 |

## 12. 正式接口清单表

| 方法 | 路径 | 用途 |
|---|---|---|
| `POST` | `/v1/batch-runs` | 创建批量启动草稿或直接启动 |
| `POST` | `/v1/batch-runs/import-file` | 解析 CSV/XLSX 并回填批次草稿行 |
| `POST` | `/v1/batch-runs/:id/validate` | 执行字段映射与预算校验 |
| `POST` | `/v1/batch-runs/:id/start` | 正式启动批次 |
| `GET` | `/v1/batch-runs/:id` | 查询批次详情 |
| `GET` | `/v1/batch-runs/:id/items` | 查询行级任务列表 |
| `POST` | `/v1/batch-runs/:id/retry` | 对失败项或选中项重跑 |
| `POST` | `/v1/batch-runs/:id/cancel` | 取消剩余未完成项 |

## 15. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 预算预估缺失 | 启动前无法给出结构化成本与配额提示 | 大批次可用性不足 | P0 |
| 正式持久化与治理深化缺失 | 当前映射与导入结果仍停留在草稿链与 file-backed 状态 | 生产级恢复与治理能力不足 | P0 |
| 批次持久化仍为 file-backed | `batch-runs-state.json` 仍是当前事实源 | 难以支撑生产级并发与恢复 | P0 |
| Worker-native 批次治理缺失 | 当前由 API 侧 `runWithConcurrency` 驱动 | 深治理、恢复与扩展能力不足 | P0 |
| 独立批次列表与导出能力缺失 | 当前入口主要停留在服务页与当前批次看板 | 运营与重度用户管理深度不足 | P1 |
