## 2. 当前异常模型总表

| 层 | 当前异常对象 | 作用 | 当前状态 |
|---|---|---|---|
| API 业务层 | `AppError` | 承载 `statusCode + code + message + details` | 已实现 |
| API 参数层 | `ZodError` | 请求体验证失败 | 已实现 |
| API 未知异常 | `Error` / `unknown` | 兜底转 `INTERNAL_ERROR` | 已实现 |
| WebSocket 实时层 | `runs.error` | 将错误消息回推前端 | 已实现 |
| Domain 层 | `Error` | 状态机非法流转 | 已实现，但未统一收敛为 AppError |
| Worker 层 | `Error` | 运行期异常、桥接等待超时、端口申请失败 | 已实现，但未统一错误码 |
| Container Bridge 层 | `Error` | secret 缺失、CLI 未启动、上下文缺失、connector 响应错误 | 已实现，但未统一错误码 |
| API SDK 层 | `Error` | HTTP 非 2xx、WS 不可用、payload 非法 | 已实现，但仅字符串化 |

## 3. API 统一错误响应结构表

| 字段路径 | 类型 | 说明 | 来源 |
|---|---|---|---|
| `error.code` | `string` | 业务错误码 | `normalizeErrorPayload` |
| `error.message` | `string` | 面向调用方的错误消息 | `normalizeErrorPayload` |
| `error.details` | `unknown` | 可选补充细节 | `AppError` / `ZodError` |
| HTTP Status | `number` | HTTP 状态码 | `statusCode` |

| 通道 | 当前格式 | 说明 |

## 7. 当前非标准化错误文本总表

| 所在层 | 当前错误文本 | 触发场景 | 当前问题 |

## 8. WebSocket 关闭语义表

| 场景 | close code | close reason | 当前行为 |
|---|---:|---|---|
| 路径参数非法 | `1008` | `invalid_run_id` | 先发 `runs.error` 再关闭 |
| run 不存在 | `1008` | `run_not_found` | 先发 `runs.error` 再关闭 |
| 其他消息处理错误 | 不主动关闭 | 无 | 当前只发送 `runs.error` |

## 9. Bridge / Worker / SDK 异常来源矩阵表

| 层 | 典型异常源 | 当前处理方式 | 当前缺口 |
|---|---|---|---|
| Worker | 端口申请、bridge 健康等待、启动参数解析 | 抛原生 `Error` | 无统一 code、无 retry 分类 |
| Container Bridge | secret 物化、MCP 配置物化、Codex PTY 状态 | 抛原生 `Error` | 无统一 code、无 audit 分类 |
| API Connector | 内部 HTTP 非 2xx、JSON 解析失败 | 抛原生 `Error` | 无 internal error code 约定 |
| SDK | HTTP/WS 失败 | 转字符串回调 | 无结构化 error object |

## 10. 建议正式错误码域总表

| 错误域 | 建议前缀 | 适用对象 |
|---|---|---|

| Credential | `CREDENTIAL_*` | 凭证缺失、失效、越权、轮换中 |
| MCP | `MCP_*` | 连接失败、风控拒绝、白名单拒绝、能力未授权 |
| Realtime | `REALTIME_*` | 订阅失败、连接关闭、payload 非法 |
| Runtime | `RUNTIME_*` | 容器启动失败、bridge 失联、Codex 不可用 |
| Quota | `QUOTA_*` | 并发超限、预算超限、存储超限 |
| Audit | `AUDIT_*` | 审计导出失败、数据不完整 |

## 12. 状态码使用建议矩阵表

| 状态码 | 适用场景 |
|---|---|
| `400` | 参数非法、路径非法、请求格式错误 |
| `401` | 未认证 |
| `403` | 已认证但无权访问 |
| `404` | 资源不存在 |
| `409` | 状态冲突、重复审批、终态继续操作 |
| `422` | 业务输入通过格式校验但不满足业务规则 |
| `429` | 并发或配额超限 |
| `500` | 未知内部错误 |
| `502` | 上游 MCP / 第三方服务异常 |
| `504` | 运行时等待超时 |

## 13. 错误重试语义矩阵表

| 错误码 / 错误域 | 客户端建议 | 服务端建议 |
|---|---|---|
| `VALIDATION_ERROR` | 不自动重试 | 返回明确字段错误 |
| `RUN_NOT_FOUND` | 不自动重试 | 记录访问来源 |
| `RUN_STATUS_INVALID` | 不自动重试 | 返回当前状态与允许动作 |
| `FILE_NOT_FOUND` | 可人工刷新后重试 | 检查文件同步链 |
| `MCP_UPSTREAM_UNAVAILABLE` | 指数退避重试 | 上游熔断与状态监控 |
| `RUNTIME_BRIDGE_TIMEOUT` | 引导用户稍后重试 | 记录容器与 bridge 健康指标 |
| `QUOTA_LIMIT_EXCEEDED` | 不自动重试 | 引导审批或升级配额 |
| `INTERNAL_ERROR` | 谨慎重试 | 打日志并标注 trace id |

## 15. SDK 错误对象改造建议表

| 当前状态 | 建议改造 |
|---|---|
| `onError(error: string)` | 改为 `onError(error: { code?: string; message: string; statusCode?: number; retryable?: boolean })` |
| HTTP 非 2xx 只抛 `HTTP_<status>` | 读取后端 `error.code/message/details` 再抛结构化对象 |
| WS `runs.error` 只含 message | 扩展为 `{ code, message, details?, runId? }` |

## 16. 日志与审计补充要求表

| 层 | 建议补充 |
|---|---|
| API | 所有 `AppError` 记录 `code, statusCode, requestId, runId?, workspaceId?` |
| Worker | 运行时错误记录 `runId, workspaceId, phase, attempt` |
| Container Bridge | 记录 `runId, component, action, error` |
| SDK / 前端 | 记录 `runId, route, transport, error.code?`，便于问题回溯 |

## 17. 当前缺口总表

| 项目 | 当前缺口 |
|---|---|
| 错误域覆盖 | Auth / Workspace / Credential / MCP / Quota 尚无正式错误码 |
| WebSocket 错误结构 | 当前只有 message，没有 code 和 details |
| SDK 错误对象 | 当前仅字符串化，前端难做分类处理 |
| Worker / Bridge 错误模型 | 当前多为原生 `Error`，缺统一规范 |
| 审计联动 | 错误缺少 trace id、actor、workspace 维度的正式审计记录 |

## 20. 错误模型收口顺序表

| 阶段 | 动作 | 收口结果 |
|---|---|---|
| Phase 1 | 扩展正式错误码域 | 业务错误分类完整 |
