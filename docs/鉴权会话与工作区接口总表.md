## 9. 路由守卫与初始化顺序总表

| 页面/入口 | 首屏初始化依赖 | 守卫条件 | 未满足时动作 |
|---|---|---|---|
| Dashboard `/dashboard/workshops` | `GET /v1/auth/session` + `GET /v1/workspaces` | 已登录且存在可见工作区 | 跳登录页或工作区创建页 |
| Dashboard `/dashboard/instances/:id` | 同上 + `currentWorkspace` | 已登录且当前工作区可见该 run | 跳实例列表或 403 |

| H5 工坊页 | `GET /v1/auth/session` 或游客态检查 | 首发建议要求登录 | 跳登录页 |
| H5 任务页 | `GET /v1/auth/session` + 当前工作区 | 已登录且可访问该 run | 跳任务列表或 403 |
| H5 我的 | `GET /v1/auth/session` + `GET /v1/workspaces` | 已登录 | 跳登录页 |

## 10. 授权判定矩阵总表

| 操作 | 最低角色 | 需要校验的对象 | 关键判定 |
|---|---|---|---|
| 浏览工坊目录 | `member` | `workspace`、`workshop visibility` | 当前工作区是否可见该工坊 |
| 创建 run | `operator` 或以上 | `task_version`、`session_version`、`workspace` | 当前成员是否有执行权，绑定凭证/MCP 是否在当前作用域可用 |
| 发送 run 消息 | `operator` 或以上 | `run` | 当前工作区是否拥有该 run |
| 审批 run | `approver` 或以上 | `approval`、`run` | 当前审批请求是否指派到该工作区/角色 |
| 下载 run 文件 | `member` 或以上 | `run_file` | 当前工作区是否拥有该 run，文件是否对终端用户可见 |
| 查看 Creator 包 | `creator` 或以上 | `package` | 当前工作区是否绑定该 package |
| 发布 package | `creator` + `approver/admin` 组合门 | `package_version`、`release_gate` | 当前用户是否满足发布门要求 |
| 管理成员 | `owner/admin` | `workspace_membership` | 不能越权修改同级或更高角色 |

## 11. 当前代码与正式设计之间的缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| SSO / MiniApp 登录未落地 | 当前仅实现 register/login/refresh/logout/session 基础链路 | 企业统一身份与小程序专用登录尚不能正式接入 | P0 |
| 工作区前端仍保留局部样例回退 | Dashboard 和 Mobile 仍有部分本地目录与静态摘要兜底 | 工作区体验仍存在局部非权威视图 | P0 |
| 成员 / 邀请偏好域未完全闭环 | 成员列表、邀请、接受、撤销、成员变更已落地；偏好、session revoke 与安全中心未落地 | 企业协作基础已成型，但治理深水区未完成 | P1 |
| 无 session revoke | 缺安全中心与设备管理 | 账号安全能力不足 | P1 |
| 无内部 token 消费 | `LINGBAN_INTERNAL_AUTH_TOKEN` 只有环境变量预留 | bridge/worker 到 API 的内部调用无法正式验签 | P1 |

## 14. 当前接口域阻塞表

| 阻塞项 | 当前表现 | 影响 |
|---|---|---|
| 无用户域 API | 前端无法首屏恢复 `current_user` | 登录态与守卫无法建立 |
| 无工作区域 API | 前端无法拿到权威工作区列表 | 工作区切换仍停留在样例态 |
| 无 session 刷新链 | access/refresh 生命周期不存在 | 无法形成正式长会话 |
| 无内部服务鉴权接口 | bridge / worker 无正式 token 验证 | 内部调用不可生产化 |
