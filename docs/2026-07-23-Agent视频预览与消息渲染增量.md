# Agent 视频预览与消息渲染增量

## 1. 目标

将 Agent 在 Run `targetPath` 内生成的视频文件接入会话消息、文件索引、受控预览、H5、微信小程序和 Dashboard，保证路径边界、鉴权、票据、播放器和失败状态形成完整链路。

## 2. 支持范围

| 层级 | 实现内容 | 关键约束 |
| --- | --- | --- |
| Bridge | 识别 Markdown 链接、HTML `video/source`、附件及普通路径 | 输出 target-relative path，保持原文顺序 |
| Contracts | `RunFilePreviewMode` 增加 `video` | API 与双前端共享枚举 |
| Files | 推断视频 MIME 和预览模式 | MP4/WebM/QuickTime/Ogg |
| API | 签发短期 inline 票据 | 工作区鉴权、Run 边界、no-store、nosniff |
| H5/小程序 | 会话卡片和文件页使用 Taro `Video` | 16:9、controls、全屏、失败重试 |
| Dashboard | 会话卡片和文件页使用原生 video | playsInline、metadata、下载兜底 |

## 3. 路径解析

| 输入示例 | 结果 |
| --- | --- |
| `[播放](./output/episode.mp4)` | `output/episode.mp4` |
| `<video src="./output/trailer.webm"></video>` | `output/trailer.webm` |
| `<video><source src="./output/trailer.mp4"></video>` | `output/trailer.mp4` |
| 反引号包裹的 `episode.m4v` | `episode.m4v` |
| `../outside.mp4` | 拒绝 |
| `https://example.com/a.mp4` | 保留原文，不进入本地预览链 |

## 4. 预览流程

1. Bridge 从 Agent 文本提取视频路径并写入消息附件。
2. Worker 文件事件和 Run 文件索引记录视频 MIME、对象键和 `previewMode=video`。
3. 前端调用 `GET /v1/runs/:runId/files/preview?path=...`。
4. API 校验工作区和 Run 文件权限，签发短期内联下载票据。
5. 播放器使用票据 URL 请求视频，票据到期前自动续签。
6. 视频进度拖动通过单区间 HTTP Range 获取目标字节段。
7. 索引延迟期间前端每 2 秒重试，最多 15 次。
8. 解码失败时提供重新加载、文件页查看或下载操作。

## 5. 安全约束

| 控制项 | 要求 |
| --- | --- |
| 路径边界 | 只接受当前 Run target path 内文件 |
| URL 类型 | 拒绝 HTTP、data、blob、协议相对 URL |
| 传输凭证 | 使用短期下载票据，禁止暴露本地绝对路径 |
| 响应头 | `Content-Disposition: inline`、`private, no-store`、`nosniff` |
| Range | 有效区间返回 206，非法或越界区间返回 416 |
| 分享边界 | 任务会话和任务文件页继续禁止微信分享 |
| 兼容性 | 文件扩展名进入识别范围，实际播放由客户端编码能力决定 |
