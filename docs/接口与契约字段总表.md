## 12. 对外 HTTP API 契约总表

| 方法 | 路径 | 请求参数 | 请求体 | 响应 | 主要副作用 |
|---|---|---|---|---|---|
| `GET` | `/v1/runs` | 无 | 无 | `RunSnapshot[]` 列表 | 读取 run 聚合 |
| `POST` | `/v1/runs` | 无 | `CreateRunInput` | `CreateRunResponse` | 创建 run、注入首轮 prompt、触发编排 |
| `GET` | `/v1/runs/:runId` | `runId` | 无 | `RunSnapshot` | 读取单 run |
| `GET` | `/v1/runs/:runId/files` | `runId` | 无 | `RunFileEntry[]` 或聚合结果 | 读取文件索引快照 |
| `GET` | `/v1/runs/:runId/files/tree` | `runId` | 无 | 文件树结构 | 遍历 run 目标目录 |
| `GET` | `/v1/runs/:runId/files/stat` | `runId`、`path?` | 无 | 文件或目录状态 | 查询目标路径元信息 |
| `GET` | `/v1/runs/:runId/files/read` | `runId`、`path?` | 无 | `RunFileReadResponse` | 文本文件读取 |
| `GET` | `/v1/runs/:runId/files/download` | `runId`、`path?` | 无 | 文件流 | 生成下载响应头并返回 stream |
| `POST` | `/v1/runs/:runId/messages` | `runId` | `SendRunMessageInput` | 业务返回值 | 记录用户消息并向 bridge 分发 |
| `POST` | `/v1/runs/:runId/approvals` | `runId` | `ApproveRunInput` | 业务返回值 | 提交审批决策并向 bridge 分发 |
| `POST` | `/v1/runs/:runId/approve` | `runId` | `ApproveRunInput` | 业务返回值 | 与 `/approvals` 等价的兼容路径 |
| `POST` | `/v1/runs/:runId/cancel` | `runId` | `{ reason?: string }` | 业务返回值 | 取消 run |
| `GET` | `/v1/runs/:runId/stream` | `runId` | 无 | SSE 流 | 先推 snapshot，再持续推送 backlog 与增量事件 |

## 14. 路由参数与默认值规则表

| 项目 | 当前规则 | 说明 |
|---|---|---|
| `runId` 路由参数 | `z.string().min(1)` | 当前路由层仅验证非空，未强制前缀校验 |
| 文件查询参数 `path` | `optional` | 文件相关接口允许空路径，由 service 决定默认行为 |
| `cancel.reason` | `optional` | 取消原因可选 |
| `initialMessage` | 默认 `null` | create run 时首条消息可缺省 |
| `bindings.*` | 默认空数组 | 可先创建 run，再在对话中逐步补信息 |
| `attachments` | 默认 `[]` | 发送消息时无附件也可成立 |
