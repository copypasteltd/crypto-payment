## 2. 当前代码证据映射表

| 证据点 | 当前实现 | 工程含义 |
|---|---|---|
| `GET /v1/runs/:runId/files/tree` | 已实现 | 当前文件浏览优先扫宿主机目录，target workspace 不可访问时回退 `run_files` 索引 |

## 3. 当前文件链路与目标对象存储链路对照表

| 维度 | 当前模式 | 目标模式 |
|---|---|---|
| 权威源 | 宿主机 `targetPath` | 对象存储 + 元数据索引 |
| 上传 | 不存在 | 预签名直传或服务端中转 |
| 下载 | 本地文件流 | 短时下载令牌或签名 URL |
| 预览 | 文本直读 | 统一 preview gateway |
| 文件索引 | 动态扫描 + 聚合快照 + lazy index write | `run_files` 基础索引已落地，后续提升为权威源 |
| 权限控制 | 仅 `targetPath` 边界 | 账户、工作区、run、文件级鉴权 |

## 8. 上传链路总表

| 步骤 | 当前状态 | 正式行为 |
|---|---|---|
| 1. 选择文件 | 已在前端交互层存在潜在位置 | 用户选择输入材料 |
| 2. 发起上传会话 | 当前无接口 | `POST /upload-url` 返回预签名 |
| 3. 客户端直传 | 当前无 | 直传对象存储 |
| 4. 完成确认 | 当前无 | `POST /complete-upload` 写入 `run_file` |
| 5. run 内挂载 | 当前无统一逻辑 | worker 将输入映射到 `/workspace/inputs` |
| 6. 前端收到文件更新 | 仅依靠轮询或 event | `file.changed` 或索引刷新 |

## 9. 下载链路总表

| 步骤 | 当前行为 | 正式行为 |
|---|---|---|
| 1. 前端请求下载 | 先请求 download ticket | 请求下载授权或下载地址 |
| 2. API 校验 | 仅 run 与路径边界 | 校验用户、工作区、文件权限 |
| 3. 生成下载载荷 | 本地流式文件 | 生成签名 URL 或代理流 |
| 4. 终端执行下载 | H5 `window.open` / Mini `downloadFile` | 统一由 SDK 决策终端行为 |
| 5. 记录访问 | 当前无正式日志 | 写 `file_access_log` |

## 10. 预览链路总表

| MIME 类型 | 当前能力 | 正式目标 |
|---|---|---|
| `text/*`、`json`、`md`、`csv`、`html` | 256 KB 文本预览 | 支持范围读取、分页、全文检索 |
| `pdf` | 当前建议直接下载 | 生成缩略页或 PDF 代理预览 |
| 图片 | 当前建议直接下载 | 直接内联预览或缩略图 |
| `zip` / 二进制 | 仅下载 | 保留下载 |
| 日志 | 文本预览 | 分段读取与尾部跟踪 |

## 11. 文件访问授权判定矩阵表

| 场景 | 当前规则 | 正式规则 |
|---|---|---|
| 个人空间下载 | 仅 run + path 存在 | 当前用户必须属于该个人空间 |
| 企业工作区下载 | 仅 run + path 存在 | 当前用户必须为工作区成员且具读权限 |
| 审计文件下载 | 当前无区分 | 仅审计/管理员角色可读 |
| Creator 导出文件 | 当前无区分 | 受 package/release/replay 权限控制 |
| 预览 | 与下载同级 | 可比下载更宽，但必须经过鉴权 |

## 12. 下载授权状态机总表

| 状态 | 含义 | 可流转 |
|---|---|---|
| `issued` | 已签发下载授权 | `consumed`、`expired`、`revoked` |
| `consumed` | 已被使用 | 无或再次签发新授权 |
| `expired` | 到期失效 | 无 |
| `revoked` | 被提前撤销 | 无 |

## 16. 生命周期与保留策略总表

| 文件来源 | 保留建议 |
|---|---|
| 输入材料 | 跟随 run 或由业务配置保留期 |
| 输出产物 | 默认长期或转归档 |
| 日志 | 30-180 天 |
| 审计导出 | 7-30 天可下载期，长期保留 manifest |
| 预览缩略图 | 可再生成，短期保留 |

## 17. 当前缺口与补齐顺序表

| 优先级 | 缺口 | 影响 | 补齐动作 |
|---|---|---|---|
| P0 | 无正式 upload session / multipart / presigned 能力 | 大文件与直传链无法正式生产化 | 在现有 create/put/finalize 之上补 `upload-url / complete-upload / multipart` |
| P0 | 运行产物生命周期治理不足 | 运行产物已对象化入索引，但缺归档、回收、去重与审计 | 让 outputs/archive/artifacts 在 `run_files` + object storage 之上补生命周期治理 |
| P1 | 文件 preview 覆盖不足 | Office/复杂 PDF/更细 preview variant 仍缺 helper | 扩展 `previewRunFile()` 与 preview variant |
| P1 | 下载授权未形成正式 grant 对象 | 无法形成完备审计与吊销 | 补 `file_download_grant` 正式域 |
| P1 | preview 变体治理不足 | 仍缺缩略图、分页、缓存与生命周期策略 | 建 preview variant/gateway |
