# 灵办词元 数据迁移与切换总表

## 1. 文档信息

| 字段 | 内容 |
|---|---|
| 文档名称 | 数据迁移与切换总表 |
| 适用范围 | 从当前 file-backed 原型迁移到正式 PostgreSQL / Object Storage / 队列体系 |
| 统计日期 | 2026-07-08 |
| 当前事实 | API 当前以 `.json` / `.jsonl` 为权威源；文件直接位于 target path；尚无正式数据库 |
| 文档目标 | 明确迁移对象、目标存储、迁移步骤、双写切换、验证与回滚要求 |

## 2. 当前权威源总表

| 对象 | 当前权威源 | 当前位置 | 当前说明 |
|---|---|---|---|
| Run 聚合 | `FileBackedRunsRepository` | `.lingban-data/api/runs/*.json` | 唯一正式元数据权威源 |
| 事件流 | `InMemoryRunEventBus` + JSONL | `.lingban-data/api/events/*.jsonl` | 用于 backlog 与重放 |
| 运行目录 | 本地文件系统 | `<runRoot>/target|inputs|outputs|runtime|logs...` | 运行期文件权威源 |
| 产物文件 | 本地 `outputs` / `target` | runRoot 目录 | 尚未进入对象存储 |
| 前端工坊/Creator 数据 | 本地 TS 文件 | `app/dashboard/src/data/*`、`app/mobile/src/data/*` | 前端原型权威源 |

## 3. 目标正式存储总表

| 对象 | 目标存储 | 当前原因 |
|---|---|---|
| Run / Message / Approval / Artifact 元数据 | PostgreSQL | 支撑查询、过滤、审计、关系约束 |
| 事件流 | PostgreSQL 事件表或 Kafka + 冷存储 | 支撑回放、监控、审计 |
| 文件与产物二进制 | S3 / MinIO | 支撑远程下载、CDN、归档 |
| 临时运行目录 | 本地挂载卷或容器卷 | 保留运行期 I/O 能力 |
| 前端工坊/Creator 配置 | PostgreSQL + 发布资产包 | 替换本地样例数据 |
| 凭证与 MCP 配置 | PostgreSQL + Secret Manager | 支撑多租户治理 |

## 4. 源到目标映射矩阵表

| 当前对象 | 当前格式 | 目标对象 | 目标表/存储 |
|---|---|---|---|
| `run_*.json.run` | JSON | run 主记录 | `runs` |
| `run_*.json.messages[]` | JSON | 对话消息 | `run_messages` |
| `run_*.json.files[]` | JSON | 文件索引 | `run_files` |
| `run_*.json.artifacts[]` | JSON | 产物索引 | `run_artifacts` |
| `run_*.json.approvals[]` | JSON | 审批记录 | `approvals` |
| `run_*.json.input` | JSON | run 输入快照 | `run_inputs` |
| `run_*.json.startJob` | JSON | 启动载荷审计快照 | `run_launch_payloads` 或审计表 |
| `events/*.jsonl` | JSONL | 事件总线记录 | `run_events` |
| `<runRoot>/outputs/*` | 文件 | 对象存储产物 | bucket + `run_artifacts` 索引 |
| `<runRoot>/target/*` | 文件 | 工作文件与归档 | bucket + `run_files` 索引 |

## 5. 迁移阶段总表

| 阶段 | 目标 | 核心动作 |
|---|---|---|
| Phase 0 | 数据模型冻结 | 确认正式表结构、索引、约束、对象存储目录规则 |
| Phase 1 | 导入工具准备 | 编写 JSON/JSONL 扫描、转换、幂等导入器 |
| Phase 2 | 历史数据回填 | 将现有 run、消息、审批、文件索引导入 PostgreSQL |
| Phase 3 | 双写验证 | API 同时写 JSON 与 PostgreSQL，读仍走 JSON |
| Phase 4 | 读链切换 | 查询与快照读取改为 PostgreSQL，文件读取仍兼容本地目录 |
| Phase 5 | 对象存储切换 | 新增文件上传、产物写入对象存储，逐步替换本地下载 |
| Phase 6 | 旧存储退场 | JSON/JSONL 仅保留冷备份，退出主链 |

## 6. 历史数据回填步骤表

| 步骤 | 输入 | 输出 | 校验点 |
|---|---|---|---|
| 扫描 run 文件 | `.lingban-data/api/runs/*.json` | run 导入批次 | 文件数、runId 唯一性 |
| 解析聚合结构 | `RunAggregate` JSON | 规范化记录集 | schema 校验通过率 |
| 导入 run 主记录 | `run` | `runs` | 主键冲突率、状态枚举合法性 |
| 导入消息/审批/产物 | `messages[]/approvals[]/artifacts[]` | 对应子表 | 外键完整性 |
| 扫描 event JSONL | `.lingban-data/api/events/*.jsonl` | 事件记录集 | eventId/runId 有效性 |
| 建立文件索引 | 本地目录扫描 + 现有 `files[]` | `run_files` | 路径归属合法性 |
| 生成迁移报告 | 导入结果 | 报告文件 | 成功/失败/跳过统计 |

## 7. 双写阶段矩阵表

| 写入对象 | 当前主写 | 双写目标 | 切换前校验 |
|---|---|---|---|
| run 聚合 | JSON | PostgreSQL | 每个 run 快照一致 |
| 事件流 | JSONL | PostgreSQL / Kafka | 事件数一致、顺序一致 |
| 审批状态 | JSON | PostgreSQL | 审批状态与 run 状态一致 |
| 文件索引 | JSON / 目录扫描 | PostgreSQL | 路径、kind、时间戳一致 |

## 8. 切流顺序表

| 顺序 | 读链对象 | 建议切换策略 |
|---|---|---|
| 1 | `GET /v1/runs` / `GET /v1/runs/:id` | 新增 repository 抽象，灰度切换读 PostgreSQL |
| 2 | WS/SSE 回放 backlog | 改读正式事件存储 |
| 3 | 文件树与 stat | 优先走正式文件索引，缺失时回退目录扫描 |
| 4 | 下载链路 | 优先对象存储 URL，缺失时回退本地下载 |
| 5 | 审计与计费 | 正式接管为数据库查询 |

## 9. 数据一致性校验矩阵表

| 校验项 | 校验方式 |
|---|---|
| run 数量一致 | JSON 文件数对比 `runs` 行数 |
| message 数量一致 | 聚合中消息总数对比 `run_messages` 行数 |
| approval 数量一致 | 聚合中审批总数对比 `approvals` 行数 |
| artifact 数量一致 | 聚合中产物总数对比 `run_artifacts` 行数 |
| 终态一致 | JSON 中 `run.status` 对比数据库 `runs.status` |
| 事件数一致 | JSONL 行数对比 `run_events` 行数 |
| 文件索引一致 | `files[]` + 目录扫描结果对比 `run_files` |

## 10. 文件迁移与对象存储切换矩阵表

| 文件类别 | 当前位置 | 目标位置 | 迁移策略 |
|---|---|---|---|
| 输入材料 | `<runRoot>/inputs` | `s3://bucket/runs/<runId>/inputs/` | 上传后写索引 |
| 输出产物 | `<runRoot>/outputs` | `s3://bucket/runs/<runId>/outputs/` | 产物完成时即时上传 |
| 工作文件 | `<runRoot>/target` | `s3://bucket/runs/<runId>/target/` | 按需归档 |
| 日志文件 | `<runRoot>/logs` | `s3://bucket/runs/<runId>/logs/` 或日志平台 | 定时归档 |
| runtime 文件 | `<runRoot>/runtime` | 冷存储或不迁移 | 主要用于诊断 |

## 11. 回滚矩阵表

| 切换点 | 回滚策略 |
|---|---|
| 双写阶段 | 保持 JSON 主读，关闭 PostgreSQL 读路径 |
| PostgreSQL 主读阶段 | 切换 repository 实现回到 JSON 读 |
| 对象存储下载阶段 | 回退为本地文件下载 |
| 事件总线正式化阶段 | 回退为 JSONL backlog |

## 13. 当前阻塞项总表

| 阻塞项 | 当前原因 | 优先级 |
|---|---|---|
| 正式 PostgreSQL repository 未落地 | 目前仅 file-backed repository | P0 |
| 对象存储客户端未落地 | 当前下载与预览完全依赖本地文件 | P0 |
| 事件正式存储方案未定 | JSONL 仅适合单机原型 | P0 |
| 迁移脚本缺失 | 无法回填现有 run 数据 | P1 |
| 双写一致性校验缺失 | 无法安全切换主读链路 | P1 |

## 16. 最短切流顺序表

| 阶段 | 动作 | 收口结果 |
|---|---|---|
| Phase 1 | 落地 DB schema 与 repository | 具备双写基础 |
| Phase 2 | 编写迁移/校验脚本并导历史数据 | 可量化历史一致性 |
