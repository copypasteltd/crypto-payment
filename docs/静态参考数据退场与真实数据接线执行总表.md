## 7. 适配器去硬编码收敛表

| 当前函数 | 当前实现方式 | 风险 | 正式替换方案 | 迁移动作 |
|---|---|---|---|---|
| `inferWorkshopName()` | 仅作为 `run.catalogMetadata.workshopName` 缺失时的 fallback | 新任务族或历史 run 仍可能误判 | 后端返回 `run.catalogMetadata.workshopName` | 继续压缩 fallback 覆盖面 |
| `normalizeWorkspaceId()` | 仅作为 `run.catalogMetadata.workspaceContextKey` 缺失时的 fallback | 工作区 slug 改名或历史 run 仍可能失效 | 前端统一使用正式 `workspace.id` / `run.catalogMetadata.workspaceContextKey` | 删除 normalize 层 |
| `inferWorkspaceName()` | 仅作为 `run.catalogMetadata.workspaceContextName` 缺失时的 fallback | 多语言来源对历史 run 不权威 | `/v1/workspaces` 或 `run.catalogMetadata.workspaceContextName` 返回多语言名称 | 继续压缩 fallback 覆盖面 |
| `inferWorkshop()` | 仅作为 `run.catalogMetadata.workshopName` 缺失时的 fallback | H5 与 Dashboard 对历史 run 仍可能不一致 | 后端返回 `run.catalogMetadata.workshopName` | 共享 ViewModel |
| `statusMeta()` 内业务文案 | 前端手工映射 | 双端提示语可能漂移 | 保留前端展示层，状态原因改读后端 | 抽出统一 tokens / copy map |

## 9. 前端状态层重构表

| 当前 store/query | 当前问题 | 目标形态 | 执行动作 |
|---|---|---|---|
| `currentWorkspaceId` 本地持久化 | 可能指向无权限工作区 | 与 `/v1/auth/me` 协商，失效时回退到服务端默认空间 | bootstrap 时校验 |
| `visibleWorkshops/Services` 基于本地数组过滤 | DashboardShell / Workshops 在认证工作区下已停止静态目录回退；剩余问题集中在预览态样例治理与少量 Creator 参考引用 | 基于 Query 缓存与服务端返回可见范围 | 将静态目录严格收敛为 preview-only fixtures |
| `mergedInstances = static + live` | Dashboard Instances 已拆分为 `live / empty / static`，认证工作区不再混入样例实例 | `listRuns` 为唯一权威源，样例数据仅保留 demo 开关 | 将同类数据模式继续统一到 Shell 与剩余实例周边入口 |
| `findVisibleTask/Service/Workshop` | 路由 fallback 指向静态首项 | 路由参数无效时改为服务端 404 / empty state | 删除静态首项回退 |
| `CreatorPage` 内组件级元数据 | 无法缓存、无法切页复用 | Query + route-based data loader | 分域加载 package/release/governance |
