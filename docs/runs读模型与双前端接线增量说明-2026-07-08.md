| 项目 | 本次结果 |

## 4. API 变更

### 4.1 `GET /v1/runs`

| 参数 | 类型 | 说明 |
|---|---|---|
| `q` | `string` | 关键字检索 |
| `status` | `RunStatus` | 原始状态精确过滤 |
| `viewStatus` | `running \| approval \| done \| failed \| cancelled` | 视图态过滤 |
| `attentionMode` | `todo \| running \| done` | 列表注意力态过滤 |
| `entrySurface` | `dashboard \| h5 \| mini-program` | 入口面过滤 |
| `tag` | `string` | 按派生 tag 过滤 |

### 4.2 `GET /v1/runs/summary`

| 字段 | 说明 |
|---|---|
| `total` | 当前工作区命中的 runs 总数 |
| `pendingApprovalsCount` | 当前工作区 pending approval 总数 |
| `outputsReadyCount` | 已有结果文件或已成功完成的 runs 数 |
| `latestUpdatedAt` | 当前工作区最近更新时间 |
| `byStatus` | 原始状态计数 |
| `byViewStatus` | 统一视图态计数 |
| `byAttentionMode` | 统一注意力态计数 |
| `byEntrySurface` | 入口面 facet |
| `byTag` | tag facet |
| `byWorkshop` | 工坊 facet |
