## 14. 验收判定表

| 验收项 | 判定标准 |
|---|---|
| 搜索一致性 | Dashboard 与 Mobile 对同一工作区、同一查询返回同源结果集合 |
| 最近使用真实性 | 最近使用由真实用户访问事件驱动，不依赖静态样例数组顺序 |
| 收藏工坊成立 | 用户可收藏、取消收藏、跨端查看同一收藏列表 |
| 工作区隔离 | 不同工作区的搜索、最近使用、收藏互不串扰 |
| 深链可达 | 搜索结果与最近使用项均可打开对应工坊、服务、任务、文件页 |
