## 2. 当前事实矩阵

| 主题 | 当前证据 | 当前结论 | 当前缺口 |
|---|---|---|---|
| 凭证挂载契约 | `CredentialMount` 已支持 `env/file` | 运行时挂载语义已成型 | 无治理层实体 |
| 自动推导规则 | `launch-plan.ts` 根据 `credentialId` 推导 env/file 和 secrets 子目录 | API 已有最低可用解析器 | 规则写死在代码中 |
| Secret 物化 | API broker 负责加密存储与 internal materialize，下游 `SecretLoader.materialize()` 负责 env/file 注入 | Bridge 启动前可按 run 最小集合完成注入 | 仍缺结构化物化审计与终态清理证据 |
| 引用图与生命周期治理 | `/v1/credentials/:id/usages` 聚合 run + binding；`/suspend` / `/revoke` 支持 `block / allow-active-runs / cancel-active-runs`；后台 sweep 会自动执行到期冻结与待轮换状态收口 | 凭证治理已能显式处理 active-run impact，并自动冻结到期凭证 | 外部 KMS/Vault 与跨系统撤销回调仍未闭环 |
| Host/Container 改写 | `run-lifecycle.ts` 会重写 file mount 与 `authRef` | 文件型凭证视角切换已存在 | 无 trace/job 元数据 |
| Creator 凭证治理语义 | `CreatorPage` 已有 credentials 分区、轮换计划、只读挂载、第三方引用文案 | 前端治理入口已固定 | 未接真实数据 |

## 3. 凭证生命周期状态机总表

| 状态 | 含义 | 可流转 |
|---|---|---|
| `draft` | 已登记但未完成校验 | `active/disabled` |
| `active` | 可被绑定与注入 | `rotation_due/suspended/revoked/expired` |
| `rotation_due` | 临近轮换窗口 | `active/suspended/revoked/expired` |
| `suspended` | 暂停使用，不再允许新绑定 | `active/revoked` |
| `revoked` | 主动吊销 | 终态 |
| `expired` | 到达有效期 | `suspended/revoked` |
| `compromised` | 疑似泄露或事故态 | `revoked/replaced` |
| `replaced` | 已被新版本替换 | 终态 |

## 4. 凭证作用域矩阵

| 作用域 | 当前建议 | 典型场景 | 正式要求 |
|---|---|---|---|
| `platform` | 平台内建能力共享 | 第一方图像、平台内部服务 | 严格限制查看与导出 |
| `workspace` | 企业级共享凭证 | 企业邮箱 OTP、共享 Notion Token | 需管理员治理与轮换 |
| `user` | 用户私有凭证 | 用户自带 API key、个人第三方连接器 | 仅所有者可见 |
| `run` | 临时派生凭证 | 临时 session 文件、短时 token | 到期自动回收 |

## 5. 注册与绑定执行链总表

| 步骤 | 执行方 | 输入 | 动作 | 输出 |
|---|---|---|---|---|
| 1 | 用户/管理员 | 凭证名称、作用域、用途 | 创建 `credential` 元数据 | `credential_id` |
| 2 | API/Broker | 明文或引用 | 安全存储密钥材料 | `credential_version` |
| 3 | 治理层 | 工作区、服务、package 或 connector | 建 `credential_binding` | 绑定关系 |
| 4 | Run 创建 | `credentialIds[]` | 解析为 `CredentialMount[]` | runtime payload |
| 5 | Worker/Bridge | mount 列表 + secret values | 物化 env/file | 运行态 secret |

## 6. 当前推导规则矩阵

| 条件 | 当前规则 | 代码位置 | 当前风险 |
|---|---|---|---|
| `credentialId` 包含 `cookie/session/oauth/json/storage-state/browser` | 走 `file` 挂载 | `resolveCredentialMount()` | 规则硬编码 |
| 其他一般 API key | 走 `env` 挂载 | `resolveCredentialMount()` | 名称误判风险 |
| 浏览器类 file secret | 写入 `/workspace/secrets/browser/` | `inferSecretFolder()` | 目录规则不可配置 |
| OAuth 类 | 写入 `/workspace/secrets/oauth/` | `inferSecretFolder()` | 目录规则不可配置 |
| MCP 类 | 写入 `/workspace/secrets/mcp/` | `inferSecretFolder()` | 目录规则不可配置 |

## 7. 注入模式执行矩阵

| 模式 | 当前支持 | 适用场景 | 正式要求 |
|---|---|---|---|
| `env` | 已支持 | API key、短 token | 最小进程暴露、掩码日志 |

| `none` | 通过空值表达 | 公共无鉴权能力 | 仍需审计与网络策略 |

## 8. 轮换执行链总表

| 步骤 | 执行方 | 输入 | 动作 | 输出 |
|---|---|---|---|---|
| 1 | 治理层 | `credential_id` | 创建新 `credential_version` | 新版本 |
| 2 | Broker/存储层 | 新密钥材料 | 落安全存储 | 新 secret material |
| 3 | Binding 层 | 受影响 binding | 切换默认版本或双版本过渡 | 更新绑定 |
| 4 | Run 启动评估 | 旧版本仍被引用 | 决定允许旧 run 延续或强制失效 | 生命周期决策 |
| 5 | 审计层 | 轮换完成 | 记录 `credential.rotated` | 审计事件 |

## 9. 吊销与失效回流矩阵

| 场景 | 正式动作 | 回流结果 |
|---|---|---|
| 用户主动吊销 | 标记 `revoked`，停止新 run 使用 | 相关 connector/服务进入不可用态 |
| 到期失效 | 标记 `expired` | Creator 治理页和 run 启动页显示阻断 |
| 疑似泄露 | 标记 `compromised`，强制停用 | 触发高优先级审计和通知 |
| 工作区解绑 | 删除或停用 `credential_binding` | 对应 package/service 不再可启动 |
| 运行中发现缺失 | `SecretLoader` 抛错并阻断启动 | 回流到凭证治理与审批链 |

## 10. 运行时物化与清理矩阵

| 阶段 | 当前行为 | 正式要求 |
|---|---|---|
| payload 解析 | 生成 `CredentialMount[]` | 挂带 `credential_version_id`、`scope`、`expires_at` |
| host/container 改写 | file path 双视角改写 | 增加 trace 与 secret lineage |
| Bridge 物化 | env/file 注入 | 记录来源、写入审计、最小暴露 |
| 运行结束 | 当前无统一清理 | env 清除、file 删除、目录回收 |
| 启动失败 | 当前直接抛通用错误 | 结构化失败码 + 清理中间 secret 文件 |

## 14. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无正式 `credential/credential_version/credential_binding` | 只有运行时 mount 抽象 | 无法治理与轮换 | P0 |
| 推导规则写死在代码 | 仅凭命名推导 env/file | 容易误判 | P0 |
| 外部 KMS/Vault provider 未接入 | 当前 broker 为 `local-envelope`，主密钥仍由部署配置注入 | 跨环境密钥治理、托管轮换与更强硬件边界不足 | P0 |
| 无吊销传播链 | 吊销后无法自动影响 package/run | 安全风险 | P1 |
| Secret 物化无审计与清理 | 文件与 env 暴露不可治理 | 安全与合规风险 | P1 |
