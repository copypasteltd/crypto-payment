## 2. 风险分级口径表

| 维度 | L1 | L2 | L3 | L4 |
|---|---|---|---|---|
| 影响范围 | 单模块内部 | 单仓库主链 | 跨仓主链 | 系统级/生产级 |
| 用户影响 | 几乎无感 | 局部受阻 | 核心能力受阻 | 任务无法执行或数据风险 |
| 恢复成本 | 小时级内低成本修复 | 需要专项修复 | 需要跨角色联动 | 需要停机、回滚或数据恢复 |
| 管理动作 | 记录即可 | 纳入周跟踪 | 纳入里程碑 gate | 进入阻塞清单与升级机制 |

## 3. 概率分级口径表

| 级别 | 定义 | 判断口径 |
|---|---|---|
| P1 | 低概率 | 现有证据显示短期内不易触发 |
| P2 | 中低概率 | 有设计缺口，但触发路径较少 |
| P3 | 中高概率 | 已出现明确缺口，随开发推进大概率触发 |
| P4 | 高概率 | 当前状态已经构成持续风险或必然阻塞 |

## 4. 当前总体风险快照表

| 风险域 | 当前等级 | 主要原因 | 直接影响 |
|---|---|---|---|
| 正式数据层 | L4 / P4 | 尚未落地 PostgreSQL schema、migration、repository | 无法形成正式权威数据源 |
| 运行编排层 | L4 / P3 | Worker 未真正消费队列，Docker 生命周期未执行 | 无法承载真实 run 并发 |
| 凭证与 MCP 治理 | L4 / P3 | 第三方 MCP 与私有凭证治理链未完成 | 多租户隔离与合规性不足 |
| 对象存储与文件治理 | L3 / P4 | artifact 上传、版本化、签名下载未落地 | 文件链无法进入正式态 |
| 认证与工作区权限 | L4 / P4 | API 与前端均未接入正式 auth / workspace ACL | 无法对外开放真实用户访问 |
| 可观测性与运维 | L3 / P3 | 日志、指标、告警、回滚链未建立 | 故障定位和恢复效率低 |
| 前后端联调闭环 | L3 / P3 | 前端主要仍以原型态数据和骨架适配为主 | 真业务路径验证不足 |
| 发布与环境体系 | L3 / P4 | Shared Dev / Staging / Production 未建立 | 无法形成稳定交付节奏 |
| 本地运行验证能力 | L3 / P4 | Docker daemon 未启动，当前只能验证构建与静态产物 | runtime 真执行证据缺失 |

## 6. 风险触发条件表

| 编号 | 触发条件 | 触发后表现 | 需要立刻采取的动作 |
|---|---|---|---|
| TRT-001 | 单 run 状态与磁盘 JSON 不一致 | 前端看到状态回退、丢消息、丢审批 | 冻结新增接口，优先替换正式 DB repository |
| TRT-002 | 多用户同时创建 run | Worker 无法接单或状态卡住 | 优先接入 Redis + BullMQ，暂停并发验证范围扩张 |
| TRT-003 | 文件体积上升或产物数量增多 | 本地目录读写变慢、下载超时 | 接对象存储、分块下载、文件索引 |
| TRT-004 | 引入外部第三方 MCP | 凭证外泄或网络边界不可控 | 引入 connector policy、沙箱网络、审计日志 |
| TRT-005 | 新增真实企业用户试运行 | 权限模型无法满足隔离要求 | 先补 auth/workspace/role model，再开放试点 |
| TRT-006 | 需要线上问题追查 | 无日志链、无 tracing | 先补 observability，再推进外部发布 |
| TRT-007 | 前后端同步推进多模块联调 | 契约频繁变更导致返工 | 冻结 SDK 契约与 schema 版本 |
| TRT-008 | 发布后出现 run 大量失败 | 无回滚与降级策略 | 立即切换旧版本并停发新 runner tag |

## 7. 风险应对策略表

| 策略类型 | 适用场景 | 具体动作 | 责任角色 |
|---|---|---|---|
| 规避 | 会直接触发生产级违规或数据风险 | 在完成 auth、DB、secret 治理前不开放真实多租户生产流量 | Product / Architect |
| 降低 | 已知缺口可通过工程补齐 | 建正式数据层、对象存储、监控、回滚链 | Backend / Runtime / Platform |
| 转移 | 可交由平台或托管服务承担 | 托管 PostgreSQL、Redis、对象存储、镜像仓库 | Platform |
| 接受 | 仅限低级别且短周期风险 | 原型期保留演示数据和局部静态内容 | Product / Frontend |

## 8. 外部依赖风险矩阵表

| 依赖项 | 当前依赖方式 | 风险点 | 建议治理 |
|---|---|---|---|
| Codex CLI | 运行时核心依赖 | 版本行为变化可能影响事件解析 | 锁版本、做兼容性回归测试 |
| Docker Runtime | 每 run 容器执行基座 | 宿主资源争抢、网络与卷挂载错误 | 预设资源上限、健康检查、回收机制 |
| Redis / BullMQ | 队列底座 | 队列堆积、重复消费、消息丢失 | 幂等任务模型、DLQ、可观测性 |
| PostgreSQL | 权威数据层 | schema 演进不稳会影响全链路 | migration 策略、回滚演练、索引评审 |
| Object Storage | 文件与产物存储 | 下载授权与版本治理不足 | 签名 URL、版本化、生命周期策略 |
| 第三方 MCP | 扩展能力来源 | 凭证泄漏、网络越权、协议不稳定 | connector registry、准入审查、审计 |
| 外部模型 API | 图像/内容生成等能力 | 成本波动、速率限制、失败重试 | 配额、熔断、缓存、降级策略 |

## 9. 安全与合规风险表

| 风险项 | 当前状态 | 影响 | 必要控制项 |
|---|---|---|---|
| 秘钥明文分发 | 未建立集中式 secret broker | 凭证泄漏风险高 | KMS/Vault、短期 token、审计 |
| 用户工作区越权 | 未建立正式 ACL | 可能读取他人 run 与文件 | workspace boundary、资源级鉴权 |
| 第三方 MCP 出网不可控 | 尚未建立网络策略 | 可能访问未授权外部资源 | egress policy、allowlist、出网审计 |
| 文件下载无正式签名链 | 当前以本地文件直读为主 | 敏感文件暴露 | 签名 URL、权限校验、审计 |
| 审批动作无正式审计 | 审批虽有接口但治理层未完善 | 合规追责困难 | 审批日志、操作人、时间戳、来源 IP |
| 容器逃逸与宿主污染 | runner image 尚未形成完整安全策略 | 平台风险高 | rootless、只读挂载、seccomp、资源限制 |

## 11. 成本构成总表

| 成本域 | 主要构成 | 计费方式 | 成本敏感度 |
|---|---|---|---|
| 计算成本 | API、Worker、Runner 容器 CPU/内存 | 按实例或资源时长 | 高 |
| 存储成本 | PostgreSQL、对象存储、日志存储 | 按容量与读写量 | 中高 |
| 网络成本 | 出网流量、对象存储下载流量、第三方 MCP 出网 | 按流量 | 中高 |
| 第三方 API 成本 | 模型 API、图像生成 API、外部 SaaS | 按调用量/Token/请求数 | 高 |
| 运维成本 | 监控、告警、值班、回滚演练 | 人力与平台订阅 | 中 |
| 安全治理成本 | KMS/Vault、审计留存、合规工具 | 按租用与调用量 | 中 |

## 12. 成本驱动因素表

| 成本项 | 主要驱动变量 | 波动来源 | 控制抓手 |
|---|---|---|---|
| 单 run 容器成本 | run 时长、CPU、内存、并发数 | 长会话、重任务、异常未回收 | 超时回收、资源档位、配额 |
| 对话成本 | 消息数、上下文长度、模型单价 | 长上下文、多轮追问 | 压缩上下文、裁剪历史、模型分层 |
| 文件成本 | 上传体积、下载次数、保留周期 | 多媒体产物、长时间归档 | 生命周期策略、冷热分层 |
| 第三方 MCP 成本 | 调用次数、外部接口单价 | 频繁轮询、无缓存 | 连接器限流、缓存、熔断 |
| 监控成本 | 指标维度、日志量、保留天数 | 大量 debug 日志 | 采样率、日志等级、保留策略 |

## 15. SLI / SLO / SLA 矩阵表

| 能力 | SLI | 建议 SLO | 对外 SLA 备注 |
|---|---|---|---|
| API 可用性 | 成功响应率 | `>= 99.9%` | 正式生产后定义 |

| 审批指令成功率 | 审批请求被正确执行的比例 | `>= 99.9%` | 需审计闭环支持 |

## 16. 告警阈值表

| 告警项 | 建议阈值 | 告警级别 | 处理动作 |
|---|---|---|---|
| API 5xx 比例 | 5 分钟内 > 2% | P1 | 检查最新发布、回滚或限流 |
| Run 启动失败率 | 15 分钟内 > 5% | P1 | 检查 worker、Docker、runner image |
| 队列积压 | 等待任务数 > 100 或持续增长 | P1 | 扩 worker、查消费失败 |
| 对象存储上传失败率 | 10 分钟内 > 3% | P2 | 检查存储、网络、签名策略 |
| 单机 CPU | 持续 10 分钟 > 85% | P2 | 扩容或限制 run 并发 |
| 单机内存 | 持续 10 分钟 > 80% | P2 | 回收异常 run、调整资源档位 |
| 凭证注入失败 | 单小时 > 1 次 | P1 | 冻结相关 connector 发布 |
| 第三方 MCP 失败率 | 15 分钟内 > 10% | P2 | 熔断并降级该 connector |

## 17. 事件分级与升级表

| 等级 | 定义 | 升级路径 | 目标响应时间 |
|---|---|---|---|
| Sev-1 | 多数用户无法创建或运行任务；存在数据或安全风险 | Runtime/Backend/Platform 立即联动，通知负责人 | 15 分钟内 |
