## 4. 当前 API 文件接口总表

| 接口 | 当前作用 | 返回 |
|---|---|---|
| `GET /v1/runs/:runId/files` | 返回 run 快照中的文件列表 | `RunFileEntry[]` |
| `GET /v1/runs/:runId/files/tree` | 优先扫描 target path；工作目录不可访问时回退 `run_files` 索引 | `RunFileEntry[]` |
| `GET /v1/runs/:runId/files/stat` | 查询单文件或目录状态，必要时回退索引记录 | `RunFileEntry` |
| `GET /v1/runs/:runId/files/read` | 读取文本内容，必要时回退对象存储副本 | `RunFileReadResponse` |
| `GET /v1/runs/:runId/files/download` | 下载文件流，必要时回退对象存储副本 | 二进制流 |
| `POST /v1/runs/:runId/uploads` | 创建上传会话 | `CreateRunUploadResponse` |
| `PUT /v1/runs/:runId/uploads/:uploadId/content` | 上传附件内容 | `RunUploadRecord` |
| `POST /v1/runs/:runId/uploads/:uploadId/finalize` | 将上传件挂为对话附件 | `FinalizeRunUploadResponse` |
| `POST /v1/runs/:runId/download-tickets` | 创建短时下载票据 | `CreateRunDownloadTicketResponse` |
| `GET /v1/downloads/:ticketId` | 根据票据下载，必要时回源对象存储 | 二进制流或 307 跳转 |

## 6. 当前文件安全约束表

| 约束项 | 当前规则 | 证据 |
|---|---|---|
| target path 边界 | 仅允许访问当前 run 的 `targetPath` 内路径 | `resolvePathWithinTarget()` |
| 目录读取 | 目录不可直接 `read` | `readRunFile()` |
| 目录下载 | 目录不可直接下载 | `createDownloadDescriptor()` |
| 文本读取上限 | `256 * 1024 bytes` | `MAX_TEXT_BYTES` |
| 路径越界错误 | `FILE_PATH_INVALID` | `file-access.ts` |
| 文件缺失错误 | `FILE_NOT_FOUND` | `file-access.ts` |

## 7. 当前文件类型与体验矩阵表

## 11. 当前缺失上传链路总表

| 缺失项 | 当前影响 |
|---|---|
| 上传 URL 接口 | 用户无法正式上传输入材料 |

## 16. 建议端到端上传链路表

| 步骤 | 执行方 | 说明 |
|---|---|---|
| 1 | 前端 | 选择文件并发起上传请求 |
| 2 | API | 校验用户、工作区、run 权限，返回预签名 URL |
| 3 | 前端 | 直传对象存储 |
| 4 | API | 记录元数据并写入 `run_files / run_inputs` |
| 5 | Worker / Bridge | 将所需输入挂载或同步到 `/workspace/inputs` |
| 6 | 前端 | 实时收到 `file.changed` 或刷新文件列表 |
