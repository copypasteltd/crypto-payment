# 灵办词元 审计计费与配额总表

## 1. 文档信息

| 字段 | 内容 |
|---|---|
| 文档名称 | 审计计费与配额总表 |
| 文档类型 | Audit, Billing & Quota Matrix |
| 适用范围 | `agent-workshop` 全工作区 |
| 基准日期 | 2026-07-07 |
| 关联文档 | `docs/产品需求草案.md`、`docs/后端设计文档.md`、`docs/风险与成本监控表.md`、`docs/数据库与正式数据模型总表.md` |
| 使用目的 | 将 execution ledger、审计事件、成本账本、配额对象、预算阈值、保留导出要求与当前缺口统一表格化 |

## 2. 核心治理对象映射表

| 概念 | 建议系统对象 | 说明 | 来源口径 |
|---|---|---|---|
| Execution Ledger | `audit_logs + cost_ledgers + run summary` | 统一运行账本 | 产品与后端已明确 |
| 审计记录 | `audit_logs` | 行为可追责 | 产品与后端已明确 |
| 成本记录 | `cost_ledgers` | 费用归集与预算分析 | 产品已明确 + 治理推导 |
| 配额策略 | `quota_policies` | 并发、预算、存储限制 | 治理推导 |
| 超限事件 | `quota_events` | 记录超限与拦截 | 治理推导 |

## 3. 审计域范围总表

| 审计域 | 需要记录的对象 | 说明 |
|---|---|---|
| 运行生命周期 | `run` | 创建、排队、启动、结束、取消、失败 |
| 对话链路 | `run_message` | 用户消息、系统消息、Agent 回复 |
| 审批链路 | `approval` | 请求、通过、拒绝、备注 |
| 文件链路 | `run_file`、`run_artifact` | 上传、下载、读取、删除、导出 |
| 凭证治理 | `credential` | 新建、绑定、轮换、停用 |
| MCP 治理 | `mcp`、`mcp_binding` | 注册、审核、首次调用、停用 |
| Creator 发布 | `task_version`、`session_version` | 发布、灰度、回滚、下架 |
| 成员与权限 | `workspace_member` | 邀请、改角色、移除 |
| 成本与配额 | `cost_ledger`、`quota_policy` | 配额变更、预算调整、超限拦截 |

## 16. 审计与配额执行点矩阵表

| 执行点 | 需要校验的配额 | 需要写入的审计 |
|---|---|---|
| 创建 run | 并发 run、日启动数、预算余额 | `run.created` |
| 发送消息 | 模型 token、实时连接 | `message.user` |
| 上传输入文件 | 上传体积、文件数 | `file.uploaded` |
| 首次调用高风险 MCP | MCP 调用额度、风险策略 | `mcp.first_call_confirmed` |
| 下载产物 | 下载次数、带宽 | `artifact.downloaded` |
| 发布版本 | 发布权限与配额 | `task_version.published` / `session_version.published` |
| 导出审计 | 导出频率与下载权限 | `audit.exported` |

## 17. 风险等级与审计强度矩阵表

| 风险等级 | 典型动作 | 审计强度 |
|---|---|---|
| `low` | 普通查看、普通下载 | 基础记录 |
| `medium` | 启动 run、常规外部 API 调用 | 结构化记录 |
| `high` | 共享凭证使用、管理员配置变更 | 完整记录 + 操作人 |
| `critical` | 发布内容、外部提交、第三方高风险 MCP | 完整记录 + 审批链 + 导出能力 |

## 18. 保留、导出与脱敏矩阵表

| 数据类型 | 在线保留建议 | 导出方式 | 脱敏要求 |
|---|---|---|---|
| 审计日志 | 长期 | CSV / JSONL / 审计报告 | 隐去明文密钥与敏感输入 |
| 成本账本 | 长期 | CSV / BI 接口 | 可保留金额与 provider |
| 运行消息 | 6-24 个月 | JSONL | 脱敏敏感字段 |
| Trace 包 | 策略控制 | 打包下载 | 脱敏 secret 引用 |
| 审批记录 | 长期 | PDF / CSV / JSON | 保留审批链 |
| 文件下载日志 | 6-12 个月 | CSV | 可保留对象键与路径摘要 |

## 20. 当前缺口总表

| 治理对象 | 当前状态 | 缺口 |
|---|---|---|
| Execution Ledger | 仅有运行事件与前端概念 | 无正式数据库模型和查询接口 |
| Audit Log | 未实现 | 无全域审计表、无导出 |
| Cost Ledger | 未实现 | 无 provider 维度归集 |
| Quota Policy | 未实现 | 无软硬阈值、无超限拦截 |
| Download Audit | 未实现 | 文件下载不可追责 |
| Publish Audit | 未实现 | Creator 发布和回滚无正式账本 |
