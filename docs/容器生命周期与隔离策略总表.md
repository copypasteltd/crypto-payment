## 3. 当前运行模式与目标运行模式对照表

| 维度 | 当前模式 | 目标模式 |
|---|---|---|
| bridge 执行位置 | 本地模式为宿主机 Node 进程；Docker 模式为每 run 容器内 bridge | 每 run 独立容器内 bridge |
| 容器执行 | 已具备 `docker create / start / inspect / stop / rm` 代码主链 | 真正 `docker run / inspect / stop / rm` 或 K8s Pod |
| 生命周期控制 | `startLocalBridgeProcess()` 或 `startDockerBridgeProcess()` + `/health` | worker 统一控制容器和 bridge 生命周期 |
| 运行隔离 | runRoot 已隔离，计算隔离未真正验证 | 文件、网络、CPU、内存、PIDs、进程空间都隔离 |
| 清理策略 | 本地 stop 能力已有，目录回收未形成作业 | 容器销毁、目录保留、产物归档、日志保留完整闭环 |

## 4. 实例生命周期阶段总表

| 阶段 | 触发点 | 当前责任模块 | 当前输出 |
|---|---|---|---|
| `CREATED` | API 创建 run | `RunsService.createRun()` | run 聚合、首轮 system prompt、seed files、seed approval |
| `READY` | worker 预检通过 | `startRunJob()` | 状态事件 `READY` |
| `QUEUED` | worker 接单 | `startRunJob()` | 状态事件 `QUEUED` |
| `WORKSPACE_PREPARED` | 目录准备完成 | `prepareRunWorkspace()` | `PreparedRunWorkspace` |
| `CONTEXT_BUILT` | host/container 上下文改写完成 | `run-lifecycle.ts` | `hostBridgeContext`、`containerBridgeContext` |
| `RUNTIME_MATERIALIZED` | runtime 文件写入完成 | `materializeRunRuntime()` | 7 个 runtime 物料文件 |
| `LAUNCH_PLAN_READY` | launch plan 生成 | `buildContainerLaunchPlan()` | `ContainerLaunchPlan` |
| `BRIDGE_STARTING` | 启动本地 bridge 或 Docker bridge 运行时 | `startLocalBridgeProcess()` / `startDockerBridgeProcess()` | 本地子进程或容器、控制端口 |
| `BRIDGE_HEALTHY` | `/health` 检查通过 | `waitForHealth()` | `controlUrl` 可用 |
| `RUNNING` | bridge 注册并回传状态 | bridge / API | `RUNNING` 状态、消息流、文件事件 |
| `WAITING_APPROVAL` | 高风险动作需审批 | bridge / API | 审批节点挂起 |
| `SUCCEEDED / FAILED / CANCELLED` | 会话结束 | bridge / API | 终态、产物、日志 |
| `CLEANUP_PENDING` | 终态后待回收 | 目标 worker job | 容器销毁与目录治理 |

## 5. per-run 目录隔离矩阵表

| 路径 | 宿主机路径 | 容器路径 | 隔离作用 |
|---|---|---|---|

| `home` | `<runRoot>/home` | `/workspace/home` | 进程 HOME 隔离 |
| `tmp` | `<runRoot>/tmp` | `/workspace/tmp` | 临时文件隔离 |
| `browser-profile` | `<runRoot>/browser-profile` | `/workspace/browser-profile` | 浏览器状态隔离 |
| `mcp` | `<runRoot>/mcp` | `/workspace/mcp` | MCP 配置与脚本隔离 |

| `logs` | `<runRoot>/logs` | `/workspace/logs` | 运行日志隔离 |

## 10. 凭证与 MCP 隔离策略总表

| 对象 | 当前策略 | 当前实现 |
|---|---|---|
| `env` 型凭证 | 注入实例进程环境变量 | `SecretLoader.materialize()` |
| `file` 型凭证 | 写入实例 `secrets` 目录，只读挂载 | `SecretLoader.materialize()` + `buildContainerLaunchPlan()` |
| container 视角 file mount | 强制转为 posix 路径 | `rewriteCredentialMount(mode=container)` |

| MCP file authRef | host/container 两侧分别改写 | `rewriteMcpBinding()` |
| 第三方远程 MCP | 标记为 `remote-unmanaged` | `buildServerDefinition()` |

## 13. 失败场景与恢复动作总表

| 场景 | 当前表现 | 当前恢复 | 正式要求 |
|---|---|---|---|
| 工作目录创建失败 | `startRunJob()` 抛错 | run 失败 | 记录失败原因并回收半成品目录 |
| runtime 物料写入失败 | `materializeRunRuntime()` 抛错 | run 失败 | 明确失败阶段与告警 |
| bridge 健康检查超时 | `waitForHealth()` 超时 | 当前启动失败 | 自动重试与失败分类 |
| bridge 进程异常退出 | `completion` 返回非零 | run 失败 | 重试策略、错误码分类 |
| 端口占用或分配失败 | `allocatePort()` 抛错 | 启动失败 | 自动重试 |
| secret 缺失 | `SecretLoader` 抛错 | 启动失败 | 回流凭证治理与审批链 |
| MCP 配置无效 | `McpMaterializer` 抛错 | 启动失败 | 标记 connector 风险并阻断发布 |

## 14. 回收与保留策略总表

| 对象 | 当前状态 | 正式目标 |
|---|---|---|
| 运行容器 | Docker 模式下已具备 `stop` + 兜底 `rm -f` 代码路径 | 终态立即销毁 |
| `runRoot` | 当前持久保留 | 按保留策略清理 |
| `outputs` | 保留 | 归档到对象存储 |
| `logs` | 保留 | 结构化采集后归档 |
| `runtime` 物料 | 保留 | 归档关键证据，过期清理非必要文件 |
| `secrets` | 当前写入本地目录 | 实例结束后强制销毁或轮转 |
| `browser-profile` | 当前保留 | 按策略删除或仅保留必要状态 |

## 15. 当前缺口与补齐顺序表

| 优先级 | 缺口 | 影响 | 补齐动作 |
|---|---|---|---|
| P0 | Docker daemon 实机联调未完成 | 无法给出真实容器现场证据 | 完成 daemon 环境联调与证据采集 |
| P0 | secrets/browser-profile 精细回收未形成策略 | 磁盘和敏感状态残留风险 | 扩展 cleanup policy |
| P0 | 当前 inputs/runtime/mcp 挂载均可写 | 边界偏宽 | 收紧只读挂载策略 |
| P1 | 无健康重试与失败分类 | 启动稳定性不足 | 增加 error code + retry |
| P1 | 无 rootless/seccomp/readOnlyRootfs 策略 | 容器安全不足 | 在正式 runtime 补齐 |
