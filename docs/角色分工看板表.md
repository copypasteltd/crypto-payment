## 2. 角色定义表

| 角色 | 核心职责 |
|---|---|
| Architect | 定义系统边界、关键路径、风险模型、阶段 gate |
| Backend Engineer | 负责 API、DB、auth、audit、业务域后端实现 |
| Runtime Engineer | 负责 worker、Docker、bridge、runtime 隔离 |
| Frontend Engineer | 负责 dashboard、mobile、api-sdk 接线与体验 |
| Security / Platform Engineer | 负责 credential、MCP、CI/CD、部署、安全策略 |
| QA / Integration Engineer | 负责联调、验收、证据归档、回归 |
| Product / Delivery Owner | 负责优先级、排期、目标对齐、交付决策 |
