## 2. 当前我的页模块结构表

| 模块 | 当前来源 | 当前作用 |
|---|---|---|
| 当前账号头部 | `currentWorkspace` + `/v1/me/summary` | 展示当前空间与任务数量 |
| Profile Stats | `/v1/me/summary.profileMetrics` | 展示文件数、回执数、收藏工坊数、待处理数 |
| 当前工作区卡片 | `/v1/me/summary.currentWorkspace + metrics` | 展示当前工作区、角色摘要、root 路径 |
| 收藏工坊 | `/v1/me/favorites/workshops` | 展示当前工作区常用工坊与深链入口 |
| 我的资产 | `/v1/me/assets` + 匿名 fallback | 展示最近资产 |
| 授权中心 | `/v1/me/authorizations` + quota/billing 明细查询 + 匿名 fallback | 展示连接器、凭证、额度与治理摘要 |
| 通知与待办 | `/v1/notifications` + 工作区邀请 / quota 提醒补充 | 展示正式通知、待处理动作与回流入口 |
| 工作区切换 sheet | `auth.session.workspaces` + `workspaceEntries` fallback | 切换当前空间 |

## 3. 当前数据派生来源表

| 字段 | 当前派生方式 | 当前问题 |
|---|---|---|
| `files` 数 | `/v1/me/summary.profileMetrics.totalAssetsCount` | 当前仍基于 run 文件读模型聚合，不是独立资产账本 |
| `receipts` 数 | `/v1/me/summary.profileMetrics.receiptAssetsCount` | 当前统计口径已固定为 `receipt` 类资产 |
| `pending` 数 | run 状态计数 + 正式通知未读数混合呈现 | 正式待办对象仍未独立拆域 |
| `assetEntries` | `/v1/me/assets.items` | 已正式对象化；未形成独立资产持久化域 |
| `authEntries` | `/v1/me/authorizations.entries` | 已正式对象化；授权明细与治理写路径仍分散在各域 |
| `favoriteEntries` | `/v1/me/favorites/workshops.items` | 已正式对象化；当前仅覆盖工坊级收藏 |
| `favoriteWorkshopsCount` | `/v1/me/summary.profileMetrics.favoriteWorkshopsCount` | 已与收藏列表同源，不再用可见工坊数替代 |
| `workspace role` | `/v1/me/summary.currentWorkspace.role` | 已有正式字段，静态预置空间仍会 fallback 到展示文案 |

## 5. 资产沉淀来源矩阵表

| 来源事件 | 当前表现 | 正式资产写入 |
|---|---|---|
| `artifact.ready` | 结果文件进入任务页 | 写 `asset_entry` |
| `files.synced` / `file.changed` | 文件列表刷新 | 根据 `is_visible_to_user` 更新 `asset_entry` |
| `run.status.changed -> SUCCEEDED` | 我的页完成数增加 | 刷新 `profile_summary` / `notice_summary` |
| 文件下载 | 当前不记录 | 增加 `asset_access_log` |

## 14. 阻塞项表

| 阻塞项 | 当前原因 | 影响 | 优先级 |
|---|---|---|---|
| 无独立资产持久化域 | `/v1/me/assets` 仍由 run 文件读模型聚合 | 我的页资产还不能长期治理 | P0 |
| 授权明细页未落地 | 当前只有 `/v1/me/authorizations` 摘要 | 用户仍不能进入更细粒度授权详情 | P1 |
