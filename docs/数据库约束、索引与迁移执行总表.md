## 2. 当前持久化事实矩阵

| 对象 | 当前权威源 | 当前格式 | 当前限制 |
|---|---|---|---|
| run 聚合 | `runs/<runId>.json` | 单 JSON | 无事务、无并发控制、无筛选索引 |
| 事件 backlog | `events/<runId>.jsonl` | JSONL | 仅单进程重放 |
| 文件索引 | 运行时扫描 `targetPath` | 内存对象 | 无正式索引表 |
| 产物列表 | run 聚合内嵌数组 | JSON 内嵌 | 无对象存储元数据 |
| 审批记录 | run 聚合内嵌数组 | JSON 内嵌 | 无待审批查询能力 |
| 资产对象 | 文档与前端模板 | 无正式库表 | 无 lineage、发布、回滚能力 |
| 权限对象 | 文档与前端语义 | 无正式库表 | 无多租户授权判定 |

## 4. 主外键与删除策略执行矩阵

| 表 | 主键建议 | 关键外键 | 删除策略 | 说明 |
|---|---|---|---|---|
| `workspace_members` | `wmb_*` 或复合唯一键 | `workspace_id -> workspaces.id`、`user_id -> users.id` | 逻辑删除优先 | 成员历史需保留 |
| `workshop_task_bindings` | `wtb_*` | `workshop_id -> workshops.id`、`task_id -> tasks.id` | 物理删除可行 | 关系对象 |
| `task_versions` | `tsv_*` | `task_id -> tasks.id`、`session_version_id -> session_versions.id` | 禁级联删除 | 版本需稳定可追溯 |
| `session_versions` | `sev_*` | `session_id -> sessions.id`、`lineage_parent_version_id -> session_versions.id` | 禁级联删除 | 发布历史不可丢失 |
| `mcp_bindings` | `mbd_*` | `credential_id -> credentials.id` 可空 | 逻辑停用 | 绑定关系需审计 |
| `runs` | `run_*` | `workspace_id -> workspaces.id`、`task_version_id -> task_versions.id`、`session_version_id -> session_versions.id`、`requested_by_user_id -> users.id` | 禁删除，仅归档 | 执行记录权威源 |
| `run_inputs` | `rin_*` 或 bigint | `run_id -> runs.id` | 跟随 run 归档 | 输入历史 |
| `run_messages` | `msg_*` | `run_id -> runs.id` | 跟随 run 归档 | 对话时间线 |
| `run_files` | `rfl_*` 或 bigint | `run_id -> runs.id` | 跟随 run 归档 | 文件索引 |
| `run_artifacts` | `art_*` | `run_id -> runs.id` | 跟随 run 归档 | 交付物 |
| `approvals` | `apr_*` | `run_id -> runs.id`、`decided_by_user_id -> users.id` 可空 | 跟随 run 归档 | 审批历史 |
| `audit_logs` | `adt_*` | `workspace_id -> workspaces.id`、`run_id -> runs.id` 可空 | 长期保留 | 审计账本 |

## 9. JSON 到 PostgreSQL 回填映射矩阵

| 当前来源 | 正式目标表 | 关键转换 |
|---|---|---|
| `<runId>.json.run` | `runs` | 字段平铺，补齐 `started_at/finished_at/container_id` 空值 |
| `<runId>.json.input` | `run_inputs` | 将 `CreateRunInput` 拆成输入主记录与系统生成槽位 |
| `<runId>.json.messages[]` | `run_messages` | 生成 `message_seq`，保留 `attachments_json` |
| `<runId>.json.files[]` | `run_files` | 根据 `path` 去重 upsert |
| `<runId>.json.artifacts[]` | `run_artifacts` | 拆出 `file_path/file_kind/size_bytes` |
| `<runId>.json.approvals[]` | `approvals` | 补齐 `approval_type/risk_level` 默认值 |
| `<runId>.json.startJob` | `run_runtime_snapshots` 或 `runs.runtime_payload_json` | 正式环境建议拆独立 runtime 快照表 |
| `<runId>.jsonl` backlog | `run_events` | 保留原始 event envelope 与顺序 cursor |

## 13. 回滚执行矩阵

| 场景 | 回滚动作 | 保留证据 |
|---|---|---|
| 双写阶段 DB 异常 | 切回 JSON 主读主写 | 差异报告、失败 SQL、异常 run 清单 |
| 主读切换后读异常 | 将读源切回 JSON，保留 DB 写入 | 切流时间点、受影响请求日志 |
| 索引或约束错误 | 回退本批迁移并重建受影响表 | migration id、DDL 变更记录 |
| 大规模数据缺失 | 恢复 JSON 备份，重新执行回填 | JSON 备份快照、回填脚本版本 |

## 14. 当前阻塞项总表

| 阻塞项 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| `packages/db` 仅为最小骨架 | API 尚无法全面接入正式 repository | 后端正式化仍受阻 | P0 |
| 事件未独立成表 | 无法做稳定重放与差异修复 | 实时与审计能力受限 | P0 |
| PostgreSQL 主读主写未切流 | migration runner 已落地，但多数 repository 仍以 file-backed 为主 | 正式数据库收益尚未完全释放 | P0 |
| 文件索引仍依赖扫目录 | 大目录和对象存储场景不可控 | 文件域能力受限 | P1 |
