## 5. `quota_policy` 状态矩阵

| 状态 | 含义 | 可流转 |
|---|---|---|
| `draft` | 草稿策略 | `active/archived` |
| `active` | 生效中 | `paused/replaced/archived` |
| `paused` | 临时停用 | `active/archived` |
| `replaced` | 被新策略替换 | 终态 |
| `archived` | 废弃 | 终态 |

## 6. `quota_counter` 更新链总表

| 步骤 | 执行方 | 输入 | 动作 | 输出 |
|---|---|---|---|---|
| 1 | 业务动作 | run/create/download/upload/mcp call | 计算指标增量 | `delta` |
| 2 | `QuotaCounterUpdater` | `delta + scope` | 落当前窗口计数 | `quota_counter` |
| 3 | `QuotaEvaluator` | `policy + counter` | 判定 healthy/warn/approval/block | `quota_decision` |
| 4 | 业务服务 | `quota_decision` | 继续 / 插入审批 / 阻断 | response 或 pending approval |
| 5 | 审计/计费 | 决策结果 | 写 `quota_event`、同步预算 | 观测与治理回流 |

## 7. 超额状态机总表

| 状态 | 含义 | 可流转 |
|---|---|---|
| `healthy` | 低于软阈值 | `soft_warned/approval_pending/blocked` |
| `soft_warned` | 达到软阈值，允许继续 | `healthy/approval_pending/blocked` |
| `approval_pending` | 等待 override 审批 | `approved_override/rejected_override/expired` |
| `approved_override` | 在当前窗口临时放行 | `healthy/blocked` |
| `rejected_override` | 审批拒绝 | `blocked` |
| `blocked` | 命中硬阈值或 override 失败 | 窗口重置或人工解除后回 `healthy` |
| `expired` | override 超时 | `blocked` |

## 8. 超额审批执行链总表

| 步骤 | 执行方 | 输入 | 动作 | 输出 |
|---|---|---|---|---|
| 1 | `QuotaEvaluator` | `policy + counter + action_context` | 判定 `require_approval` | `quota_override_request` |
| 2 | API | `quota_override_request` | 生成或绑定 `approval` | `approval_pending` |
| 3 | 前端 | 收到待审批卡片 | 展示“额度继续执行”说明 | 用户决策 |
| 4 | 审批服务 | 用户决策 | 写 `quota_override_decision` | `approved_override/rejected_override` |
| 5 | Run 服务 | override 结果 | 恢复执行或保持阻断 | run 继续或终止 |

## 13. 与审批/计费/审计联动矩阵

| 相关域 | 联动内容 |
|---|---|
| 审批域 | `quota_override_request` 绑定 `approval_id`，走统一审批 UI |
| 计费域 | `quota_counter` 消耗来自 `usage_record/cost_ledger` 或与其并行更新 |
| 审计域 | 每次超额判定、阻断、override 决策都写 `quota_event` + `audit_log` |
| 通知中心 | 软阈值、待审批、阻断均可发通知 |

## 14. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无正式 `quota_policy/counter/event` | 无法实时判定和阻断 | 额度治理不可执行 | P0 |
| API 入口未接 evaluator | 创建、下载、上传、MCP 调用都不会限流 | 成本和风险失控 | P0 |
| 超额审批无独立对象 | 不能区分业务审批和额度审批 | 治理不可追踪 | P0 |
| 前端无真实额度状态 | 用户无法理解阻断原因 | 体验与运营差 | P1 |
| 发布 gate 未接 quota 证据 | Creator 发布治理不闭环 | P1 |
