## 6. 当前实现问题表

| 问题 | 现状 | 影响等级 |
|---|---|---|

## 7. 正式偏好数据对象表

### 7.1 主对象表

| 对象 | 主键 | 核心字段 | 说明 |
|---|---|---|---|
| `user_preference_profile` | `user_id` | `theme`、`language`、`default_workspace_id`、`updated_at` | 用户级跨端偏好 |
| `workspace_preference_context` | `user_id + workspace_id` | `last_route`、`last_run_id`、`last_package_id`、`updated_at` | 工作区上下文恢复 |
| `draft_preference_entry` | `user_id + workspace_id + draft_type + resource_id` | `content`、`sensitivity_level`、`updated_at`、`expires_at` | 云草稿能力，可按策略开启 |
| `preference_audit_event` | `event_id` | `user_id`、`workspace_id`、`field`、`old_value`、`new_value`、`source_surface` | 偏好变更审计 |

### 7.2 草稿敏感级别表

| 等级 | 适用内容 | 存储策略 |
|---|---|---|
| `low` | 普通任务追问草稿、排版备注 | 允许本地与云同步 |
| `medium` | 创作意见、非敏感业务说明 | 默认本地，用户可开启云同步 |
| `high` | 凭证、税务标识、付款信息、法务敏感材料 | 禁止明文云同步，仅本地短期缓存或完全不缓存 |

## 8. 正式接口表

| 方法 | 路径 | 主要参数 | 返回 | 作用 |
|---|---|---|---|---|
| `GET` | `/v1/me/preferences` | 无 | `user_preference_profile` | 拉取主题、语言、默认工作区 |
| `PATCH` | `/v1/me/preferences` | `theme?`、`language?`、`defaultWorkspaceId?` | `user_preference_profile` | 更新账户偏好 |
| `GET` | `/v1/me/workspace-context/:workspaceId` | `workspaceId` | `workspace_preference_context` | 恢复工作区上下文 |
| `PATCH` | `/v1/me/workspace-context/:workspaceId` | `lastRoute?`、`lastRunId?`、`lastPackageId?` | `workspace_preference_context` | 更新工作区上下文 |
| `GET` | `/v1/me/drafts` | `workspaceId`、`draftType`、`resourceId` | `draft_preference_entry[]` | 拉取允许同步的草稿 |
| `PUT` | `/v1/me/drafts/:draftType/:resourceId` | `content`、`sensitivityLevel` | `draft_preference_entry` | 保存草稿 |
| `DELETE` | `/v1/me/drafts/:draftType/:resourceId` | 无 | `204` | 删除草稿 |

## 9. 前端偏好持久化策略表

| 偏好项 | Dashboard 建议 | Mobile 建议 | 服务端同步策略 |
|---|---|---|---|
| 主题 | 先本地立即生效，再异步回写 | 同 Dashboard | 登录后双向同步，冲突以最近更新时间为准 |
| 语言 | 先本地立即生效，再异步回写 | 后续 MiniApp/H5 共用 | 登录后回写用户偏好 |
| 当前工作区 | 本地即时切换，并请求正式 workspace context | 同 Dashboard | 绑定用户会话，写 `default_workspace_id` 与 `last workspace context` |
| 对话草稿 | 本地防抖写入 | 本地防抖写入 | 仅低/中敏内容允许显式云同步 |
| 最近页面 | 路由变化时更新 | 页签变化时更新 | 存 `last_route`，用于恢复 |
| 最近任务上下文 | 切换任务时更新 `last_run_id` | 同 Dashboard | 存工作区上下文 |

## 10. 本地存储与服务端职责边界表

| 数据类型 | 本地存储职责 | 服务端职责 | 备注 |
|---|---|---|---|
| 界面偏好 | 首屏无网络时快速恢复 | 账号级同步与跨端统一 | 主题、语言 |
| 工作区上下文 | 首屏先读本地，提高切换速度 | 权威记录与跨设备恢复 | 本地是缓存，服务端是正式源 |
| 草稿 | 毫秒级即时保存 | 仅策略允许的草稿同步 | 高敏草稿不进入服务端 |
| 搜索历史 | 可做短期本地 cache | 正式历史与建议来源 | 需与搜索域协同 |
| Query 缓存 | 性能优化 | 不承担业务权威 | 不应替代正式偏好对象 |

## 11. 启动与回写顺序表

| 阶段 | Dashboard | Mobile | 说明 |
|---|---|---|---|
| Step 1 | 读取本地 key 初始化 store | 读取 Taro/localStorage 初始化 store | 保证首屏立即可渲染 |
| Step 2 | 登录后请求 `/v1/me/preferences` 与 `/v1/me/workspace-context/:workspaceId` | 同 Dashboard | 拉取正式偏好 |
| Step 3 | 合并本地缓存与服务端偏好 | 同 Dashboard | 按字段和时间戳判定覆盖 |
| Step 4 | 应用主题、语言、工作区、路由恢复 | 应用主题、工作区、可选任务恢复 | UI 与正式上下文对齐 |
| Step 5 | 用户发生修改时，本地立即写入并异步 PATCH | 同 Dashboard | 保持弱网体验 |

## 12. 数据安全与合规表

| 风险点 | 当前状态 | 正式要求 |
|---|---|---|
| 本地明文草稿 | 当前存在 | 高敏草稿禁云同步，必要时禁本地持久化 |
| 工作区路径泄露 | 当前 `workspaceId/root` 保存在本地 | 本地可缓存，需避免写入更高敏材料内容 |
| 多用户共用设备 | 当前无设备级隔离策略 | 登出时清理偏好与草稿，支持“清除此设备缓存” |
| 偏好变更审计 | 当前无 | 关键偏好与工作区切换进入审计事件 |

## 15. 验收判定表

| 验收项 | 判定标准 |
|---|---|
| 主题一致性 | 同一用户在 Dashboard、H5、后续小程序登录后保持同一主题 |
| 语言一致性 | 同一用户跨端语言配置一致 |
| 工作区恢复正确 | 登录后恢复到用户上次使用的工作区与最近上下文 |
| 草稿安全 | 高敏草稿不会以明文进入不受控云端存储 |
| 偏好切换即时性 | 用户修改主题、语言、工作区时，本地立即生效，服务端异步回写成功 |
