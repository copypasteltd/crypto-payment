## 22. 当前权威性分层表

| 模型类别 | 当前权威源 | 当前前端来源 | 说明 |
|---|---|---|---|
| Run / Message / Approval / Artifact / File | `@lingban/contracts` + `app/api` | 真实 API + realtime | 当前唯一已形成前后端同构链路 |
| Workspace 展示模型 | 无后端权威源 | `dashboardData.ts` / `mobileData.ts` / `workspaceCatalog.ts` | 仍是前端静态映射 |
| Workshop / Service 展示模型 | 无后端权威源 | `dashboardData.ts` / `mobileData.ts` | 仍是前端静态模型 |
| Creator Package / Governance 模型 | 无后端权威源 | `dashboardData.ts` + `CreatorPage.tsx` 组件内元数据 | 当前无正式契约 |
| Notification 模型 | 无正式域 | 静态 notice 文案或页面隐式信息 | 当前没有统一模型 |
