## 5. 深链目标矩阵表

| 通知类型 | 默认路由 | 锚点 |
|---|---|---|
| `info_required` | `dashboard://instances/<runId>` / `/pages/tasks/detail?id=<runId>` | 对应追问消息 `messageId` |
| `approval_pending` | 实例详情 audit/对话页 | `approvalId` |
| `result_ready` | 文件页或结果页 | `file path` 或 `artifactId` |
| `run_failed` | 任务对话页 | 最近失败消息或 `run_failed` 事件 |
| `run_succeeded` | 文件页或结果摘要 | 最新结果卡片 |
| `release_review_pending` | Creator release 页 | `releaseId/gateId` |

## 8. 待办回流规则表

| 场景 | 当前行为 | 正式要求 |
|---|---|---|
| 审批待确认 | 任务列表高亮 + Mobile 我的页统计 | 同时进入通知中心、任务列表、对话内卡片 |
| 结果已完成 | 文件卡片进入任务对话 | 同时刷新我的资产并发结果通知 |
| 失败恢复 | 任务状态变 warn/danger | 生成失败通知并定位恢复建议消息 |
| 信息补充 | system prompt / agent 追问仅在对话内可见 | 生成待补充通知，支持从通知跳回指定消息 |

## 12. 阻塞项表

| 阻塞项 | 当前原因 | 影响 | 优先级 |
|---|---|---|---|
| 无完整通知持久化主表 | 当前以 run 读模型 + 已读状态仓储为主 | 详情回查与历史归档能力不足 | P0 |
| 无消息锚点消费 | 前端尚未按 `anchor_ref_id` 精确定位消息/审批/文件 | 深链体验不完整 | P0 |
| Creator 通知未接入统一域 | 包发布待审仍停留在本地页面 | 运维链不完整 | P1 |
| 站外投递未接入 | 小程序模板消息、企业 IM、短信未落地 | 跨端提醒能力不足 | P1 |
