## 2. 当前事实矩阵

| 主题 | 当前实现 | 当前结论 | 当前缺口 |
|---|---|---|---|
| Dashboard 运行时 | `i18next` 已初始化，支持 `zh/en` | 正式双语面已建立 | 资源字典极薄，未承载多数业务文案 |
| Dashboard 页面文案 | 大量使用 `t(lang, { zh, en })` 与 `l(zh,en)` | 页面能切中英 | 文案分散在组件内，不利于治理与导出 |
| Dashboard 语言存储 | `lingban.dashboard.lang` 本地持久化 | 语言偏好可保留 | 无服务端用户偏好回写 |
| Mobile 文案 | 直接中文字符串为主 | 首发中文满足当前原型 | 没有统一词条接口与扩展策略 |
| 后端多语言字段 | 设计文档已大量使用 `name_i18n/summary_i18n/...` | 数据模型方向清晰 | 真实 API 尚未回传 i18n 对象 |
| 回退策略 | `fallbackLng = "zh"` | Dashboard 已有基础回退 | 无命名空间治理、无缺词监控、无构建校验 |

## 3. 当前代码执行矩阵

| 代码位置 | 当前行为 | 结论 |
|---|---|---|
| `app/dashboard/src/lib/i18n.ts` | 初始化 `i18next`，资源仅含 `dashboard.title/operatorTitle` | i18n 运行时存在，词典治理不足 |
| `LocalizedString` | 约定 `{ zh, en }` | 组件侧本地多语言对象模式已形成 |
| `t(lang, value)` | 若为 `string` 则交给 `dashboardI18n.t()`，若为对象则直接取 `value[lang]` | 当前同时存在“词典 key 模式”和“内联对象模式” |
| `dashboardUiStore.setLang()` | 写本地存储并调用 `setDashboardLanguage()` | 语言切换只在本地生效 |
| `DashboardShell` | `document.documentElement.lang` 随语言切换 | Web 端已同步页面语言属性 |
| Mobile 页面 | 直接书写中文字符串 | 移动端未形成运行时 i18n 层 |

## 4. 文案来源矩阵

| 来源类型 | 当前示例 | 当前优点 | 当前问题 |
|---|---|---|---|
| i18n key | `dashboard.title` | 可集中治理 | 覆盖面太小 |
| 组件内 `LocalizedString` | `t(lang, { zh: "...", en: "..." })` | 写法快，适合原型过渡 | 分散、难检索、难复用 |
| 静态数据 `l()` | `dashboardData.ts` 中大量 `l(zh,en)` | 数据和文案一起可切换 | 词条治理无法独立推进 |
| Mobile 直接中文 | H5 页面大量中文文案 | 首发简单 | 后续扩展成本高 |
| 服务端 `*_i18n` | 仅存在于设计文档 | 适合正式目录和接口 | 真实接口未落地 |

## 5. 语言覆盖矩阵

## 8. 回退策略矩阵

| 场景 | 当前规则 | 正式规则 |
|---|---|---|
| Dashboard 运行时语言未命中 | `fallbackLng = zh` | 继续保留 |
| `LocalizedString` 缺 en | 当前无法显式检测 | 构建期报错或自动降级到 zh 并告警 |
| 服务端 `*_i18n` 缺 locale | 当前无真实 API | 先取请求语言，再取默认语言，再取 zh |
| Mobile 未引入 i18n runtime | 直接中文展示 | 以 `zh` 为默认，后续通过共享 helper 平滑扩展 |

## 14. 当前结构性缺口总表

| 缺口 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| Dashboard 词典覆盖率极低 | 大部分文案仍在组件内联 | 难以治理、导出、审校 | P0 |
| 存在双轨模式 | `i18next key` 与 `LocalizedString` 并存 | 一致性差 | P0 |
| Mobile 无统一 i18n 接口 | 直接中文写死 | 后续多语言扩展成本高 | P1 |
| 用户语言偏好未服务端化 | 仅本地存储 `lingban.dashboard.lang` | 多设备不同步 | P1 |
| 缺词监控缺失 | 没有 build/report | 上线后难发现回退问题 | P1 |
