## 2. 本轮目标

本轮补齐并验证以下连续业务链：

```text
创建空白 Session Project
→ 创建 Source Run
→ 启动 Codex App Server 会话
→ 完整对话
→ Capture
→ Draft / Revision
→ 脱敏审核
→ Replay
→ Seal
→ Workshop / Service / Task Version
→ Package / Candidate Binding
→ Release / Gates / Activation
→ 工坊目录发现
→ Consumer Run
→ Consumer 对话
→ Consumer Capture / 新 Draft
```
