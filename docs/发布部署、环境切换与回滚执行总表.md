| 环境 | 当前定位 | 主要用途 | 正式要求 |

## 11. 发布 Gate 与责任执行矩阵

| Gate | 当前责任方 | 通过条件 |
|---|---|---|
| Build Gate | 开发负责人 | 全部构建成功 |
| Config Gate | 后端/运维负责人 | 环境变量与 secret 校对完成 |
| Runtime Gate | 平台负责人 | runner image 可启动 |
| Smoke Gate | 联调负责人 | run 主链 smoke 通过 |
| Release Gate | 负责人 / 审批人 | 准许切环境 |
| Rollback Gate | 负责人 / 运维 | 回滚包与回滚步骤已就绪 |

## 12. 当前阻塞项总表

| 阻塞项 | 当前表现 | 影响 | 优先级 |
|---|---|---|---|
| 无正式 CI/CD | 全靠人工构建发布 | 发布成本高且易失误 | P0 |
| 无服务托管脚本/IaC | worker/bridge/runtime 无正式托管 | 难以稳定部署 | P0 |
| 无版本化回滚包 | 回滚依赖人工记忆 | 故障恢复风险高 | P1 |
| smoke 未自动化 | 上线后问题暴露太晚 | 验证不足 | P1 |
