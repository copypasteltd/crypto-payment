## 2. 审计材料分类总表

| 类型 | 当前来源 | 数据特征 | 风险等级 |
|---|---|---|---|
| run 聚合快照 | `runsRepository` 本地 JSON | 含 run、消息、审批、文件、产物 | 高 |
| bridge 事件序列 | event bus / JSONL | 高时序价值，可复盘 | 高 |
| 文件预览与下载日志 | 目标接口扩展后 | 涉及文件路径和下载行为 | 高 |
| 审批记录 | run snapshot + 后续正式 approval 域 | 涉及授权与确认动作 | 高 |
| 凭证与 MCP 引用 | runtime context / governance | 涉及外部能力边界 | 极高 |
| 发布 gate 证据 | release/replay/audit 正式域 | 涉及脱敏、回放、预算门 | 高 |
| 导出包 | audit export job | 跨对象组合材料 | 极高 |

## 3. 保留层级总表

| 保留层级 | 存储形态 | 在线访问 | 典型数据 |
|---|---|---|---|
| `hot` | 数据库 + 热对象存储 | 立即可查 | 最近 30 天 run 审计 |
| `warm` | 数据库归档表 + 对象存储 | 秒级到分钟级 | 30-180 天审计 |
| `cold` | 压缩归档对象存储 | 需导出或解压 | 180-365 天审计 |
| `archive` | 长期归档桶或离线存储 | 非即时 | 年度审计、法务留存 |
| `hold` | 法务冻结存储 | 仅授权角色可取 | 事故调查、争议材料 |

## 4. 数据类型与保留策略矩阵表

| 数据类型 | `hot` | `warm` | `cold` | `archive` | 说明 |
|---|---|---|---|---|---|
| `audit_log` | 90 天 | 275 天 | 可选 | 长期 | 审计主账本 |
| `run messages` | 30-90 天 | 90-180 天 | 365 天内可归档 | 可选 | 受隐私与成本影响最大 |
| `approvals` | 180 天 | 365 天 | 可归档 | 长期 | 审批链需保留更久 |
| `file access logs` | 90 天 | 180 天 | 365 天 | 可选 | 下载与预览追责 |
| `artifact metadata` | 180 天 | 365 天 | 可归档 | 可选 | 产物索引 |
| `credential / mcp audit` | 365 天 | 长期 | 长期 | 长期 | 高风险治理材料 |
| `release / replay evidence` | 365 天 | 长期 | 长期 | 长期 | Creator 治理证据 |
| `audit exports` | 7-30 天 | 不保留重复下载包 | 可按需重建 | 仅必要时 | 导出包本身不应长期重复占用 |

## 5. 字段级脱敏规则总表

| 字段 | 原始风险 | 存储态 | 导出态 | 说明 |
|---|---|---|---|---|
| `message.text` | 可能含 PII、税号、业务数据 | 原文存储 | 按 profile 脱敏 | 对话核心证据 |
| `attachment.path` | 可能暴露目录结构 | 原值存储 | 默认转相对路径 | 避免暴露宿主路径 |
| `targetPath` | 暴露实例根路径 | 原值存储 | 对外仅保留任务相对根 | 文件安全边界 |
| `downloadUrl` | 可能为短期签名地址 | 不长期保存明文 | 导出时去除 | 只保留对象 key |
| `credentialId` | 中风险 | 可保留 | 可保留 | ID 不等于 secret value |
| `envName` | 暴露环境变量命名 | 部分掩码 | 部分掩码 | 避免还原 secret 结构 |
| `mountPath` | 暴露容器内注入路径 | 部分掩码 | 部分掩码 | 仅治理视图保留 |
| `authRef` | 暴露凭证引用方式 | 原值存储 | 按 profile 控制 | 与 MCP 鉴权强相关 |
| `source_ip` | 个人数据 | 原值存储 | 对外仅保留网段 | 合规要求 |
| `user_agent` | 终端指纹 | 原值存储 | 默认摘要化 | 合规要求 |
| 第三方 URL `ref` | 外部系统信息 | 原值存储 | 路径遮罩 | 主机可保留 |

## 6. 导出 Profile 总表

| Profile | 面向对象 | 默认脱敏级别 | 默认内容 |
|---|---|---|---|
| `customer` | 企业客户、业务方 | 高 | run 摘要、审批结果、文件结果、脱敏消息 |
| `internal_ops` | 平台运维 | 中 | 审计日志、原始消息、运行路径、文件索引 |
| `governance` | Creator 治理、工作区管理员 | 中低 | 脱敏报告、回放差异、预算与策略证据 |
| `compliance` | 合规、法务、审计角色 | 低 | 原始证据、审批链、凭证引用态、导出清单 |

## 9. 生命周期作业总表

| 作业 | 周期 | 输入 | 输出 |
|---|---|---|---|
| `audit-hot-to-warm` | 每日 | 热数据 | 转移到 warm 层 |
| `audit-warm-to-cold` | 每周 | warm 数据 | 压缩归档 |
| `audit-export-expire` | 每小时 | 导出任务 | 删除过期下载链接或导出包 |
| `audit-hold-freeze` | 手动 | 指定 scope | 进入 hold 层 |
| `audit-retention-purge` | 每日 | 超期数据 | 清理或删除 |

## 10. 清理与冻结状态机表

| 状态 | 含义 | 可流转 |
|---|---|---|
| `active` | 正常保留中 | `warm_migrated`、`held`、`purged` |
| `warm_migrated` | 已迁入 warm | `cold_archived`、`held`、`purged` |
| `cold_archived` | 已压缩归档 | `held`、`purged` |
| `held` | 法务或事故冻结 | `released` |
| `released` | 冻结解除 | 回到原保留层 |
| `purged` | 已清理 | 无 |

## 11. 发布前脱敏检查矩阵表

| 检查项 | 检查对象 | 阻断级别 | 说明 |
|---|---|---|---|
| secret value 是否内嵌 | session 包、配置文件、提示词 | P0 | 明文 secret 一票否决 |
| 私有路径是否泄露 | targetPath、mountPath、下载路径 | P0 | 禁止对外发布宿主路径 |
| 第三方 URL 是否暴露敏感 query | connector ref、导出清单 | P1 | 保留 host，掩码 query |
| 用户材料是否含 PII 未脱敏 | 消息、附件摘要 | P0 | 对外导出必须处理 |
| 调试回放是否保留敏感截图 | replay 证据 | P1 | 受 profile 控制 |

## 12. 当前缺口与补齐顺序表

| 优先级 | 缺口 | 影响 | 补齐动作 |
|---|---|---|---|
| P0 | 无正式 retention/hold 模型 | 审计生命周期不可治理 | 新建 retention 域 |
| P0 | 导出脱敏规则未落地 | 导出边界不可控 | 建 profile + masking pipeline |
| P1 | 无归档对象布局与清理作业 | 存储成本与合规风险高 | 建 archive/purge jobs |
| P1 | 发布前脱敏仅停留在治理语义 | Creator 发布 gate 无真实阻断 | 将脱敏报告纳入 `release_gate` |
